# Coins (монеты/чек/оплата) — SpaceTaxi Audio Pack N5

Звон монет: перебирание монет и 8-битные coin-звуки.

Скачано и каталогизировано автоматически (ночная сессия), в игру НЕ подключено.
Форматы: .ogg/.wav/.mp3. Файлы взяты только из публичных бесплатных источников.

## Содержимое

- coin1.wav
- coin3.wav
- coin4.wav
- coin7.wav
- coin9.wav
- handleCoins.ogg
- handleCoins2.ogg

## Источник и лицензия
- Kenney «RPG Audio» — https://kenney.nl/assets/rpg-audio — **CC0 1.0**.
  - handleCoins.ogg, handleCoins2.ogg — пересыпание монет.
- OpenGameArt «10 8bit coin sounds» (автор lukerustltd) — https://opengameart.org/content/10-8bit-coin-sounds — **CC0 1.0**.
  - coin1.wav, coin3.wav, coin4.wav, coin7.wav, coin9.wav — короткие ретро-coin (выбраны 5 из 10).
