# Brake (торможение) — SpaceTaxi Audio Pack N5

Нисходящие sci-fi тона (сброс тяги/замедление) и визг покрышек (луп для скольжения).

Скачано и каталогизировано автоматически (ночная сессия), в игру НЕ подключено.
Форматы: .ogg/.wav/.mp3. Файлы взяты только из публичных бесплатных источников.

## Содержимое

- brake_tire_squeal_loop.wav
- lowDown.ogg
- phaserDown1.ogg
- phaserDown2.ogg
- phaserDown3.ogg

## Источник и лицензия
- Kenney «Digital Audio» — https://kenney.nl/assets/digital-audio — **CC0 1.0**.
  - phaserDown1..3.ogg, lowDown.ogg — нисходящие тона («замедление»).
- OpenGameArt «Car tire squeal skid loop» (автор looneybits) — https://opengameart.org/content/car-tire-squeal-skid-loop — **CC BY 3.0** (требует атрибуцию автора при публичном использовании).
  - brake_tire_squeal_loop.wav — визг покрышек, луп.
