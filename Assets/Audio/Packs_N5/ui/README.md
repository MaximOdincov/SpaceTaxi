# UI (клики/наведение) — SpaceTaxi Audio Pack N5

Клики кнопок, наведение (rollover) и селекты для интерфейса.

Скачано и каталогизировано автоматически (ночная сессия), в игру НЕ подключено.
Форматы: .ogg/.wav/.mp3. Файлы взяты только из публичных бесплатных источников.

## Источник и лицензия
- Kenney «UI Audio» — https://kenney.nl/assets/ui-audio — **CC0 1.0**.
  - click1..5.ogg — нажатия кнопок; mouseclick1.ogg / mouserelease1.ogg — мышь; rollover1..3.ogg — наведение.
- Kenney «Interface Sounds» — https://kenney.nl/assets/interface-sounds — **CC0 1.0**.
  - click_001.ogg, select_001.ogg, tick_001.ogg — клик/выбор/тик.
