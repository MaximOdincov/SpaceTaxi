# Repair (ремонт) — SpaceTaxi Audio Pack N5

Механические звуки ремонта: лязг, трещотка, скрип, глухие стуки.

Скачано и каталогизировано автоматически (ночная сессия), в игру НЕ подключено.
Форматы: .ogg/.wav/.mp3. Файлы взяты только из публичных бесплатных источников.

## Содержимое

- metalClick.ogg
- metalLatch.ogg
- repair_clank1.wav
- repair_lightclunk1.wav
- repair_mechanical1.wav
- repair_mechanical2.wav
- repair_rattle1.wav
- repair_squeakyclick1.wav

## Источник и лицензия
- OpenGameArt «Mechanical Sounds» (автор bmaczero) — https://opengameart.org/content/mechanical-sounds — **CC0 1.0**.
  - repair_clank1.wav, repair_mechanical1.wav, repair_mechanical2.wav, repair_rattle1.wav (трещотка), repair_squeakyclick1.wav (скрип), repair_lightclunk1.wav (лёгкий стук). Префикс repair_ добавлен при каталогизации.
- Kenney «RPG Audio» — https://kenney.nl/assets/rpg-audio — **CC0 1.0**.
  - metalClick.ogg, metalLatch.ogg — щелчки металла.
