# Music Radio (радио: весёлое/пафосное) — SpaceTaxi Audio Pack N5

Три трека для внутриигрового «радио» такси.

Скачано и каталогизировано автоматически (ночная сессия), в игру НЕ подключено.
Форматы: .ogg/.wav/.mp3. Файлы взяты только из публичных бесплатных источников.

## Содержимое

- radio_frozen_jam_loop.ogg
- radio_happy_adventure_loop.mp3
- radio_happy_arcade_tune.mp3
