## Чекпоинт 1 — починка запуска (Н12.1)

Симптом воспроизведён точно: чёрный мир + HUD; камера (0,0,-10) ortho=5, корабль стоит на
стартовой, 29 тел существуют. Корни:
1. **Регресс Н11.4** (мой): CreateView тоста собирал view через UiBox — CanvasGroup добавлялся
   `?? AddComponent`, который на fake-null Unity-ссылке НЕ триггерится (оператор `??` не вызывает
   перегруженный ==) → MissingComponentException в ToastNotifier.Awake рвал пул на старте.
   Фикс: отдельные стейтменты GetComponent → if null → AddComponent → доступ.
2. **ГЛАВНЫЙ УРОК НОЧИ: `unity-cli recompile` НЕ импортирует внешние правки файлов.** Правка
   .cs на диске без AssetDatabase.Refresh() не попадает в сборку — редактор гоняет старый код,
   line-номера исключений врут (pdb-смещения). Отсюда часы раскопок (symptom: «уп_to_date» при
   неактуальной сборке). ПРОТОКОЛ Н12+ : patch → AssetDatabase.Refresh() → recompile → тесты.
3. После фикса: свежий старт — камера у борта (ortho=150), мир виден, консоль 0 ошибок,
   пул тостов CG-alive (Temp/n12_fixed.png).
