4. **v3 (текущая)** — режим такси: заказы «забери 🙋 → доставь 🏠», посадка/взлёт, станции ⛽🔧, счёт доставок

## 3. Финальная концепция игры (всё подтверждено пользователем)

**Название для техпредложения (требование преподавателя — название = формула):**
«Экшен с элементами экономической игры в стиле научной фантастики» (Space Taxi — как подзаголовок в скобках)

**Жанр:** экшен (пользователь сам определил по классификации с ru.wikipedia «Классификации компьютерных игр»; «аркада» и «симулятор» отвергнуты после обсуждения)

**Завязка (в документ не пишем — только для понимания):** герой случайно попал в систему, разбил свой корабль на планете крупной таксистской корпорации. Корабли корпорации — беспилотные, управляются дистанционно. Работает оператором-таксистом, копит на возвращение.

**Цель игры:** заработать на лучший корабль, прокачать до максимума, пройти сложный длинный маршрут и вылететь из галактики домой. На финальном маршруте игрок летит ЛИЧНО (не дистанционно) — авария = поражение.

**Мир:** одна большая 2D-карта — мультизвёздная система, без дозагрузок:
- **Планеты** — разный размер/масса → разное притяжение; посадка в любую точку; на части планет станции (заправка + ремонт)
- **Звёзды** — сильное притяжение, жар разрушает корпус на подлёте
- **Чёрные дыры** — экстремальное притяжение; у горизонта корабль гибнет; корабль, попавший туда, МЕДЛЕННО уменьшается и исчезает с экрана (кинематографичная деталь, подтверждена)
- **Астероиды** — пояса, движутся, бьют по прочности; **кометы** — быстро пролетают систему, видны издалека (в прототипе НЕ реализованы)

**Физика:** ньютоновская гравитация от всех тел одновременно; с выключенным двигателем корабль летит дальше без замедления (в текстах НЕ писать «по инерции» — пользователю не нравится формулировка); гравитация меняет и скорость, и направление.

**Управление (прототип, финальное):**
- ПРОБЕЛ — разгон по курсу; S — тормоз; A/D — боковая тяга (изгибает траекторию, скорость не растёт — пользователю ОЧЕНЬ нравится, «летать стало интересно»)
- TAB — обзор всей карты; миникарта в углу; пунктир — прогноз траектории

**Топливо/ресурс:** единый ресурс (НЕ «деньги» и НЕ «экономика» — формулировка пользователя); тратится на: топливо, улучшения, покупку кораблей, долги. Топливо расходуется только на работу двигателей. Пустой бак вдали от планет = потерянный корабль (подтверждено).

**Аренда/долги (три механики подтверждены):**
1. Арендный корабль (только простейшая модель) с комиссией с заказа. Разбил → долг + новый корабль. 3 аварии с непогашенными долгами → увольнение = проигрыш. Выплатил долги → счётчик аварий обнуляется
2. Свой корабль разбил → долга нет, но теряешь машину И улучшения, возвращаешься к аренде
3. Улучшения ставятся ТОЛЬКО на купленные корабли (арендный всегда сток)

**Заказы:** забрать пассажира на планете А → доставить на Б. Оплата = дальность + опасность + качество. **Качество/комфорт = отсутствие столкновений + выполнение мини-квеста + время заказа** (формула пользователя). Мини-задания — требования пассажира: «торопится» → уложиться в срок; «не любит запах топлива» → без заправок; «пролететь мимо кометы» и т.п.

## 4. Ключевые параметры прототипа (index.html, версия «такси»)

- Состояния: menu | fly | landed | dead
- Константы: THRUST=95, RETRO=115, MAXV=330, STRAFE_ACC=85 (боковая тяга, ~48°/с на скорости 100), FUEL_MAX=100, FUEL_DRAIN=5.5/с тяги, HP_MAX=100, BOOST=1.15 (качель), LAND_SPEED=38, TAKEOFF_V=85, ENG_MUL=3.2
- Планеты: r=24–36 (сложность сжимает), g=26000·r·mult, ring=r·3.3+30; звёзды: mult=4.5, heat=r·3.6, ring=r·2.2; пояса на каждой 5-й планете; звёзды около каждой 4-й позиции цепочки (не ближе 550 от старта)
- Посадочный режим: у поверхности (<r+90) двигатели ×3.2, автопилот орбиты отключён (внутри кольца медленнее убегающей + руки прочь → плавная циркуляция, скорость 8/с)
- Контакт: v<38 → посадка; иначе урон (v−38)·0.9 + отскок; HP≤0 → смерть
- Взлёт: ПРОБЕЛ со стоянки, импульс 85 от центра планеты
- Станции: каждая 3-я планета цепочки, при посадке авто-заправка+ремонт
- Ключи localStorage: 'orbhop_best' (рекорд доставок)
- Debug-хук: window.__dbg (state, heading, клавиши)
- НЕ реализовано в прототипе: чёрные дыры, кометы, деньги/долги/покупка, мини-квесты, финальный маршрут, бортовой компьютер

**ГОТОВЫ (одобрены):**
1. **Общие сведения** — версия пользователя дословно: «Игрок управляет космическим кораблём и перевозит пассажиров между планетами одной мультизвёздной системы. Полёты происходят в реальном времени: разогнавшись, корабль летит дальше без работы двигателя, а его скорость и направление меняет притяжение планет — от игрока требуется точное управление и быстрая реакция. За выполненные заказы он получает ресурсы и тратит их на топливо, ремонт, корабли и их улучшения.»
2. **Концепция** — экшен, оператор-таксист; цель (вылет из галактики); основная особенность = влияние планет/гравитации на полёт; доп. особенности списком: дистанционное управление, единый ресурс, улучшения, мини-задания (головоломки + комфорт → оплата)
3. **Игровой мир** — 2D-карта/мультизвёздная система; планеты/звёзды/чёрные дыры (с медленным исчезновением корабля)/астероиды/кометы; станции; взаимодействие через посадку
4. **Игровой процесс** — цикл перевозки, фазы полёта, топливо только на двигатели, мини-задания с примерами, комфорт = столкновения+мини-задание+время, повреждения, аренда/долги/увольнение, прогресс, финальный маршрут
5. **Посадка** (аналог секции «Поединок» — противник = планета) — фазы, посадочный режим, сложность от массы
6. **Финальный маршрут** (аналог «босса») — только лучший корабль + фулл-прокачка, личное управление, авария = проигрыш
7. **Технические особенности** — Unity + C#, Rigidbody2D + свой закон обратных квадратов, прогноз траектории пунктиром, конфигурации (ScriptableObject) для мира/кораблей/заказов, TextMeshPro, частицы, камера следования + обзор, сохранения, HTML5-прототип как эталон
8. **Графика** — Unity, спрайты+частицы; миникарта, HUD (скорость/топливо/прочность/заказ), пунктир прогноза, выезжающий СЛЕВА бортовой компьютер с диалогами, посадочная индикация, экран станции, экраны завершения
