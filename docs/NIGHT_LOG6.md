## Уроки ночи (для AGENTS.md)

1. **Eval-колбэки не переживают вызов CLI**: подписки EditorApplication.update из `script eval`
   умирают при разрыве relay-клиента (тихо, без ошибок) — детерминированные замеры делай В ОДНОМ
   eval-вызове (ручные шаги Physics2D.Simulate + Invoke фиксед-апдейтов через рефлексию), либо
   slow-mo (timeScale/captureFramerate) с поллингом гвардом `isPaused=false` в каждом полле.
2. **Error Pause ловит ВСЁ**: с включённым «Error Pause» консоли любая ошибка (включая шум
   pipeline-раннера) ставит плей на паузу; SetErrorPause в Unity 6.8 недоступен через рефлексию —
   в каждом полле ставь `EditorApplication.isPaused = false`.
3. **capture_game_view при несфокусированном редакторе может отдавать неактуальный кадр**
   (3 пустых кадра при живых 1500+ частицах) — для приёмки внутриигрового визуала используй
   `UnityEngine.ScreenCapture.CaptureScreenshot("Temp/…")` из eval (в папку проекта) — он честный.
4. ParticleSystem с `useUnscaledTime=true` не замедляется timeScale И Time.captureFramerate —
   жизнь частиц 0.2-2.2с короче CLI-задержки (~1.5-2.5с): счётчики читай В ТОМ ЖЕ eval-вызове,
   где спавнишь.
5. Заметка в AGENTS.md про битый `Speedometer.prefab` устарела — префаба больше нет,
   спидометр собран кодом (`SpeedometerGauge.cs`), выбросить.
