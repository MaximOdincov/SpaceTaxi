## §3. Решения владельца (зафиксированы 2026-11-05)

1. **Архетипы УБИРАЮТСЯ** (Н-14): пассажир = имя + фразы. Задание (любой тип
   из существующих) спавнится с шансом ~50% независимо от пассажира; чаевые —
   случайные 10–25% на заказ. Подписи «Турист/Чудик» и привязки удаляются.
2. **Сеть буёв = границы мира** (Н-1): «вне связи корабль отключается — это
   основа объяснения, почему нельзя улететь за границу». Буи по краю карты,
   за кольцом сети — «ПОТЕРЯ СВЯЗЬ» (существующий Abandon-флоу).
3. **Услуги станций** (Н-3): хаб МТО = 4 отдельные кнопки (МАГАЗИН /
   УЛУЧШЕНИЯ / ЗАПРАВКА / РЕМОНТ). Обычная станция: ЗАПРАВКА = только
   заправка; РЕМОНТ = ремонт + улучшения.
4. **Настройки** (Н-16): сначала починить сломавшийся UI настроек (всё
   «слиплось»), потом добавить полноэкранный режим и доделать звук.
5. Шрифт карты: **Excalifont** — владелец скачал и положил в корень проекта,
   кириллица в шрифте ЕСТЬ (проверено владельцем 2026-11-05).
6. **Расцветки кораблей** (Н-3а): владелец сам покрасит и положит их КАК
   ОТДЕЛЬНЫЕ СПРАЙТЫ (не рантайм-тинт): у ShipConfig массив вариантов;
   витрина ротирует доступные, покупка запоминает вариант.
7. Экономика топлива (Н-4): цены 0.8/1.0/1.3/1.8 и запас 35/70/100/100%
   — стартовые, владелец подкрутит после плейтеста. Запас детерминированный
   на визит — подтверждено.

**Контекст-блок + ниже.** Макет-настроение: Excalidraw-whiteboard × старая
экспедиционная карта. Арт-промпты — §7.1 (бумага, карандашные иконки, штампы).

**СЕЙЧАС:** карта (M) строится кодом в `UI/MapScreenBinder.cs` из LevelAsset
(дети Frame/Background/Title стираются и перерисовываются). Старый вид
ВЫКИНУТЬ (без переключателя).

**ЧТО СДЕЛАТЬ:**
1. Фон: текстура бумаги §7.1 на весь экран (рваные края с прозрачностью,
   желтовато-оранжевая, подтёки). За пределами листа — тёмная подложка.
2. Объекты — карандашные иконки (§7.1): планеты (по архетипу цветной карандаш,
   базово графит), звёзды, чёрная дыра, пояса (штриховая каракуля-дуга),

3. **Орбиты**: пунктирные карандашные окружности вокруг звёзд (радиус =
   фактическая дистанция планет от звезды, лениво посчитать по телам) — тонко,
   ненавязчиво.
4. **Районы (сектора)**: подписи рукописным шрифтом + лёгкая цветная
   тонировка областей (Near/Mid1/Mid2/Far — тёплые оттенки, альфа ~0.06) —
   простыми кляксами-пятнами (спрайт-болванка × масштаб).
5. **Станции и мастерские**: иконки по флагам услуг (Н-3: HasFuel/HasRepair/
   IsHub): колонка = заправка, гаечный ключ = мастерская, шашечный флажок/дом
   = хаб. Если у планеты нет услуг — без иконки.
6. **Буи и сеть**: по краю карты (на WorldRadius) — кольцо буёв (иконка),
   соединённых пунктирной линией «сети»; внутри кольца — «связь есть», снаружи
   штриховка «нет связи» + предупреждающая надпись. Сеть = граница мира:

   «ПОТЕРЯНА СВЯЗЬ» — поменять порог/текст при необходимости, чтобы флоу
   совпадал с видимым кольцом буёв.
7. **Интерактив**: планеты, звёзды, станции (планеты с услугами) — кликабельны.

   Клик: плавный зум камеры карты к объекту (1.5–2×) + боковая панель-«записка»

   Esc/клик мимо — вернуть зум и закрыть записку.
8. **Местоположение и цель**: корабль — заметный карандашный маркер (стрелка);
   цель активного заказа — обвод-кружок (заменяет TargetGlow-пульс).
9. Шрифт: Excalifont — владелец положил в корень проекта, кириллица есть
   (подтверждено). Найти *.ttf/otf, создать TMP Font Asset (код создать

10. Легенда: мелкая «записка» в углу (иконки+значения), компас-роза,
    масштабная линейка — по арт-промптам §7.1.

**НЕ ДЕЛАТЬ:** миникарту (отдельный Н-12), механику открытия/паузы, данные.

**КРИТЕРИИ:** карта выглядит бумажной, орбиты/сектора/буи видны, объекты
кликабельны с hover-эффектом и зумом+запиской, waypoint ставится, шрифт

**РЕШЕНИЕ:** не ползунок, а пакеты: полная починка / средний / мелкий —

не починить полностью — ВИДНО на попапе заранее). Улучшения переезжают в это
окно на обычных станциях (Н-3).

**ЧТО СДЕЛАТЬ:**
1. `PricingConfig`: пакеты ремонта — `float[] RepairPackFraction = {0.25f,
   0.6f, 1f}` (доля от недостающего HP), `float[] RepairPackPriceMul =
   {0.8f, 1f, 1.2f}` (множитель базовой цены 1 кр/HP), доступность по тиру
   сети ремонта: `int RepairTier` в CelestialBodyData (1..3; хаб = 3) —
   максимальный доступный пакет: тир 1 → только мелкий (и то не всегда
   полный: пакет ограничивается `RepairTierCapByTier = {0.3f, 0.7f, 1f}` —
   долей от НУЖНОГО ремонта, видна заранее).
2. UI (окно РЕМОНТ из Н-3): 3 карточки пакетов (текущий % восстановления,
