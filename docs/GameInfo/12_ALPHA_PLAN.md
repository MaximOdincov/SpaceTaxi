## 2. Что входит / что НЕ входит

**В альфе ЕСТЬ:** полёт/посадка (из прототипа), заказы без мини-заданий, генерируемые
пассажиры (архетип + имя, без прихотей), расход топлива, авто-заправка на станциях,
гибель/респавн, провал заказа при гибели, счётчик доставок, живой HUD и карта,
тело-существа пассажиров, музыка (как есть).

**В альфе НЕТ (осознанно, бета/релиз):**
- экономика: деньги/долги/аренда/покупка кораблей/улучшения
- мини-задания пассажиров и «качество» доставки
- сюжет: монолог диспетчера, спецперсонажи
- SFX-звуки (система готова, включение — бета)
- сейвы («Продолжить») — бета
- чёрные дыры, пояса, кометы
- полноценная карта всей игры (BigMap01 — черновик на потом)

## 3. Механики альфы — детали

### 3.1 Топливо [УТВЕРЖДЕНО — схема пересмотрена 2026-09-27]

- Расход: 5.5 ед/с при работающем двигателе (константа уже в `PhysicsConfig.FuelDrainPerSecond`);
  тратится на W/S/A/D (любую тягу), пропорционально времени работы — топливо только на двигатели
- **Мало топлива (< 10%)**: индикатор как жаровая зона (WarningBanner) — «ТОПЛИВО КОНЧАЕТСЯ»
- **Бак = 0**: двигатели не работают, корабль летит дальше; баннер меняется на «ТОПЛИВО КОНЧИЛОСЬ»
- **Выход**: на бортовом компьютере (TAB) появляется команда «ОТКЛЮЧИТЬ КОРАБЛЬ» —
  нажатие = респавн как при гибели (провал заказа, счётчик доставок живёт)
- **Не нажал**: корабль дрейфует; при вылете за границу системы — баннер «ПОТЕРЯНА СВЯЗЬ» —
  корабль отключается сам (тот же респавн). Радиус границы — согласовать (см. §9.3)
- **Стоишь на планете с пустым баком (без станции)**: та же команда «ОТКЛЮЧИТЬ КОРАБЛЬ»
  на бортовом компьютере — stranded-выход есть всегда

### 3.2 Заправка/ремонт [УТВЕРЖДЕНО: авто, бесплатно]

- Часть планет уровня имеет станцию (флаг в данных тела, `HasStation` [ПРЕДЛОЖЕНО] —
  добавить в `CelestialBodyData` + чекбокс в редакторе уровня)
- Посадка на планету со станцией: бак и прочность восстанавливаются [ПРЕДЛОЖЕНИЕ:
  мгновенно, как в HTML-прототипе; визуально — иконка станции на планете и на карте]
  (2026-10-03, правка после плейтеста: смертельный удар = гибель, сервис не спасает;
  выжившему — даже с 1% корпуса — станция доводит бак и HP до 100%. Порог
  мягкой посадки 38 → 55)
- Станции НЕ на всех планетах — маршруты надо планировать (это и есть «ресурсное
  давление» без экономики)

### 3.3 Заказы [УТВЕРЖДЕНО: без мини-заданий и оплаты; поток карточек — 2026-09-27]

- Источник: бортовой компьютер (TAB), секция «ВХОДЯЩИЕ ЗАКАЗЫ» (макет уже есть в
  `10_UI_DESIGN.md` §5): карточки с кнопкой [ПРИНЯТЬ]
- **Поток карточек [УТВЕРЖДЕНО 2026-09-27]**: каждая карточка живёт ~60 с и исчезает;
  новая появляется каждые 15–30 с (случайно) → одновременно висит 2–4 предложения.
  [ПРЕДЛОЖЕНИЕ программиста] максимум 4 карточки: при переполнении старейшая вытесняется
- Заказ = пассажир + планета А (забрать) + планета Б (доставить); генерация из планет
  уровня: А ≠ Б, полный рандом [РЕШЕНО 2026-09-27; нормальный генератор — позже]
- Пассажир: генерируется (архетип из 5 в `02_STORY.md` §6 + имя/фамилия из пулов +
  портрет-«существо»); в альфе архетип — только текст и портрет, прихотей нет
- Взял заказ → сел на А (посадка!) → «пассажир на борту» → сел на Б → «доставлен» →
  счётчик доставок +1, заказ закрывается
- Цель видна: [ПРЕДЛОЖЕНИЕ] жёлтое кольцо на карте (M) и маркер на миникарте —
  жёлтый код такси уже в UI-системе

### 3.4 Гибель/респавн [УТВЕРЖДЕНО]

- HP=0 (столкновение/жар/звезда) → респавн на планете старта (как в прототипе v0.1),
  бак полный, активный заказ ПРОВАЛИВАЕТСЯ (пассажир «не дошёл»)
- То же — при потере корабля от пустого бака (§3.1)
- **Счётчики [УТВЕРЖДЕНО 2026-09-27]**: доставки И провалы (вид «3/1» на борт. компьютере);
  в альфе без последствий — задел под увольнение в бете

## 4. Механизм соблюдения правил (требование альфы)

Игра гарантирует правила кодом, а не честным словом:

| Правило | Обеспечение |
|---|---|
| Один активный заказ | состояние заказа в GameSession; кнопки [ПРИНЯТЬ] недоступны при активном |
| Пассажира можно взять/сдать только посадкой | события посадки — единственная точка смены состояния заказа |
| Топливо тратится только на двигатели | расход только при `IsPressed` тяги в ShipController |
| Пустой бак = нет тяги | двигатели не работают при Fuel ≤ 0 |
| Доставка считается только на планете Б | проверка `LandedOn == заказ.Б` |
| Провал при гибели | гибель/потеря сбрасывает активный заказ |
| Счётчик доставок честный | инкремент только в событии успешной доставки |

## 5. Графика альфы (первое оформление)

| Что | Состояние в альфе |
|---|---|
| Корабль | полноценный спрайт (замена треугольника в `Ship.prefab`). [ОТКРЫТЫЙ ВОПРОС] источник: ИИ-генерация (как планета-хаб) / бесплатные ассет-паки / рисовать |

| Карта (M) | строится КОДОМ из LevelAsset (не нарисованная копия!), живая позиция корабля, цель заказа жёлтым, станции значком |
| Миникарта HUD | живая: стрелка игрока по вектору скорости, тела в радиусе ~1000, цель жёлтым |
| Пассажиры | портреты-«существа»: [ОТКРЫТЫЙ ВОПРОС] генерация набора (5 архетипов × пара вариантов) |
| Планеты | заглушки-круги остаются (осознанно), разные цвета уже есть; станции — иконка на планете |
| Бортовой компьютер | секция заказов оживает (карточки входящих), прочие секции — макетные |

## 6. Уровень альфы: TestLevel01+
