## 1. ТЗ: редактор уровня (для программиста)

Инструмент — EditorWindow в Unity Editor (НЕ внутриигровой), пишет в `LevelAsset`,
геймплей читает из него (принцип §3 `08_PROTOTYPE_V01.md`). Приоритет пунктов:
1.1 → 1.2 → 1.4 → 1.3 → 1.5; без 1.6 редактор всё равно принимается.

### 1.1 Дополнения данных (LevelAsset)

Минимальные дополнения под мои нужды (текущие поля `Bodies`, `SpawnPoint`,
`SpawnHeading` остаются):

| Поле | Тип | Смысл |
|---|---|---|
| `SpawnMode` | enum `Landed` / `Free` | в v0.1 реализуем только Landed; Free — заглушка на будущее |
| `StartPlanetIndex` | int | планета старта = точка респавна (HP=0 → сюда) |
| `SpawnAngleDeg` | float | точка на поверхности планеты старта: 0° = восток, 90° = север |

- Точка спавна в Landed вычисляется: `Position + (cos, sin)(SpawnAngleDeg) · (Radius + отступ_корабля)`. Отступ (~3 юнита, радиус коллайдера корабля) — на усмотрение программиста, главное чтобы не пересекался с планетой на старте
- Атрибуты валидации в коде данных: `Radius` — `[Min(5)]`, `MassMultiplier` — `[Min(0.1)]`, `HeatRadius` — `[Min(0)]`
- Авторасчёт: при создании звезды в редакторе `HeatRadius = 3.6·r` (число из прототипа, остаётся правится руками)

### 1.2 Окно редактора

Меню: `Space Taxi / Level Editor`. Слева — список, справа — детали (или одна
колонка, на усмотрение программиста, главное — всё без прокрутки в 6 тел).

- Поле выбора `LevelAsset` + имя уровня (`LevelName`)
- Список тел: кнопки «+ Планета» и «+ Звезда», «Дублировать», «Удалить»; клик по строке = выбор; тип и имя видны в списке
- Панель выбранного тела: DisplayName, Type, Position X/Y, Radius, MassMultiplier, HeatRadius (только для звёзд)
- Спавн-блок: SpawnMode, StartPlanetIndex (выпадающий список имён тел), SpawnAngleDeg
- Правки применяются к ассету сразу (SerializedObject + SetDirty, стандартный Ctrl+S), без отдельной кнопки «Сохранить»

### 1.3 Визуальные подсказки в Scene View

| Элемент | Вид |
|---|---|
| Тело | контур круга + мягкая заливка; имя подписью над телом |
| Посадочное кольцо `r+90` | зелёный пунктир |
| Кольцо качели `r·3.3+30` | голубой точечный (мельче пунктира посадочного) |
| Жаровая зона звезды | оранжевый пунктир + слабая заливка |
| Спавн | маркер-треугольник (корабль) + стрелка курса от поверхности |
| Выбранное тело | линии до остальных тел с числами дистанций; дистанция < 300 — подсветка тревожным цветом |
| Рамка камеры | прямоугольник «что видит игрок» на дефолтном зуме (ortho size уточнить у программиста — открытый вопрос §5) |
| Сетка | 100×100, слабая, отключаемая |

Требование к читаемости: кольца и зоны не должны спорить между собой при
минимальном зазоре между телами (300 юнитов).

### 1.4 Перемещение тел

- Drag мышью в Scene View — основной способ; snap кратно 10, Shift = кратно 1, snap отключается
- Выбранное тело двигается стрелками клавиатуры: 1 юнит, Shift = 10
- Поля X/Y в окне — для точных чисел (позиции из этого документа вводятся именно так)
- Unity Undo (Ctrl+Z) обязателен — без него правки карт страшны
- Синхронизация выбора: клик по телу в Scene выделяет его в списке окна, выбор в списке подсвечивает в Scene

### 1.5 Живая валидация (предупреждениями, НЕ блокирует)

Список сообщений обновляется при любом изменении:

| Проверка | Порог |

| Дистанция центр-центр меньше | 260 (мин. зазор прототипа) |
| Поверхности пересекаются | расстояние < r1 + r2 |
| Жаровая зона ближе к спавну | 550 (правило прототипа, `03_WORLD_MAP.md` §4) |
| Жаровая зона задевает планету | дистанция до центра планеты < HeatRadius + r планеты |
| Спавн внутри тела | точка спавна ближе r + отступ |
| Радиус вне нормы | планеты 15–40, звёзды 46–64 (предупреждение, не запрет — полигон допускает эксперименты) |

### 2.4 Физические ориентиры (расчёт по формулам проекта)

**Почему спавн только Landed.** Свободное падение с края посадочного кольца
Гавани (d = 116) до поверхности: v ≈ sqrt(2·g·(1/r − 1/d)) ≈ 201 — урон
(201−38)·0.9 ≈ 146, это смерть со 100 HP. Нулевая стартовая скорость без
автопилота недопустима.

**Планеты** (v_круг / v_спас на краю посадочного кольца r+90, высота зоны
клампа 240 над поверхностью):

| Планета | g-параметр | v_круг | v_спас | Кламп 240 до высоты |
|---|---|---|---|---|
| Гавань (r26) | 676 000 | 76 | 108 | ~27 |
| Мишень (r20) | 520 000 | 69 | 97 | ~22 |
| Верстак (r34) | 884 000 | 84 | 120 | ~27 |
| Маяк (r24) | 624 000 | 74 | 105 | ~25 |
| Кромка (r30) | 780 000 | 81 | 114 | ~26 |

Выводы: все планеты удерживают корабль на тяге W (95, в кольце 304); для схода
с орбиты достаточно 97–120 — заметно ниже MAXV 330; ретро 115 (в кольце 368)
гасит любой разгон на подлёте.

**Звезда Печь** (g-параметр 5 850 000, жар 180 = 3.6·r):

- Ближайшая планета (Мишень) в 914 — жаровая зона никого не задевает
- Граница невозврата: v_спас = MAXV 330 на дистанции ~107 от центра → «окунуться»
  в жар по краю (180–250) и уйти можно, глубже 107 — только с бустом качели
- Притяжение звезды на местах планет: Гавань 6.1, Мишень 7.0, Верстак 6.1,
  Кромка 3.4, Маяк 2.7 усов/с² — постоянное мягкое «течение» к северу по всей
  карте: игрок сразу чувствует «гравитацию от всех тел»

### 2.5 Чему учит карта (нарастающая сложность)

1. **Взлёт** с Гавани: ПРОБЕЛ + W, знакомство с посадочным кольцом
2. **Гавань → Мишень** (332, на восток): прицеливание, торможение, первая
   посадка на маленькой планете — самая щадящая (v_круг 69)
3. **→ Верстак** (694 от Мишени, крупная): та же посадка, но масса чувствована —
   сильнее тянет у поверхности, зона клампа шире
4. **→ Маяк / → Кромка** (534–803 от старта): навигация по миникарте, длинный
   разгон до MAXV, планирование торможения заранее
5. **→ Печь** (982 на север): жаровая зона — видно урон HP, вовремя отвернуть;
   заодно качель у звезды (кольцо 195, буст ×1.15) — по желанию игрока

### 2.6 Сценарий прогона для приёмки

Взлёт с Гавани → посадка на Мишень (мягкая) → Верстак (ощутимая масса) → Маяк →
Кромка (дальний) → север к Печи: вход в жар, урон, выход живым. Плюс контроль:
HP=0 → респавн на Гавани.

## 6. Полный уровень BigMap01 — 24 планеты + 4 звезды [ПРЕДЛОЖЕНО, 2026-09-15]

По запросу координатора (2026-09-15): полноценный полигон поверх брифа v0.1 —
черновик будущей карты из `03_WORLD_MAP.md`, числа будут тюниться по плейтестам.
TestLevel01 остаётся приёмочным уровнем v0.1. Ассет уже в проекте:
`Assets/ScriptableObjects/BigMap01.asset` (сгенерирован и проверен скриптом, §6.9).

### 6.1 Концепция и принципы размещения

- **Спираль секторов** вокруг хаба: ближнее учебное кольцо → восточный куст →
  северный куст → северо-западный дальний куст. Сложность растёт с расстоянием
  («география, а не множители», `01_MECHANICS.md` §10): прыжки 316–590 → 630–890 →
  890–1390 → 1240–1350 единиц
- **Каждый следующий сектор — один-два входа** («ворота прогрессии»): восток
  открывается через Весту/Толоку, север — через Кузню и релей Буй, дальний —
  только через Ворон → М-14. Обратно можно любым путём
- **Звёзды в стороне от трасс, но рядом с соблазном**: Полярная стоит между
  релеем и кустом — срезающий коридор проходит в 600–900 от неё (тяга-помеха
  при быстром транзите)
- Радиусы планет растут к периферии (16–24 у ближних → 24–38 у дальних):
  крупная планета = сильнее гравитация (g ∝ r) = жёстче посадка, без правки масс
- Южный и юго-восточный квадранты сознательно пусты — резерв под пояса, кометы
  и дыры (§6.8)
