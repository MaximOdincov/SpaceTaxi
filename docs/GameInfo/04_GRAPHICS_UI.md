# 04 — ГРАФИКА И ИНТЕРФЕЙС

Платформа [ПРЕДЛОЖЕНО]: ПК, окно 16:9 (1920×1080, Full HD). Утвердить.

> Поведение и вёрстка всех экранов (меню, HUD, миникарта, бортовой компьютер,
> карта, пауза) — детально в `10_UI_DESIGN.md` (решения 2026-09-16). Этот док —
> верхний уровень стиля и состава.

---

## 1. Стиль [УТВЕРЖДЕНО — из техпредложения]

- Unity, спрайты + системы частиц
- 2D, вид сбоку/сверху на плоскость системы (как прототип)
- Космос: чёрный фон, звёзды-точки (параллакс минимум 2 слоя)
- Двигатели, взрывы, жар звёзд, след комет — частицы

### Стадия 1 (ядро игры) [УТВЕРЖДЕНО]

Простые заглушки, генерируемые кодом: круглые планеты/звёзды, треугольная ракета,
простые астероиды. Сначала геймплей, замена на финальные ассеты — позже.

### Стадия 2 (контент) [ПРЕДЛОЖЕНО]

- Планеты: цвет + примитивная детализация (кольца, кратеры) кодом или простыми спрайтами
- Хаб-планета: сгенерированный арт (жёлтая, чекеры, шашка) — уже в работе
- Скины пассажиров: минимальные портреты-иконки

## 2. HUD (полёт) [УТВЕРЖДЕНО — состав, дополнено 2026-09-16]

- Скорость
- Топливо (бак)
- Прочность (HP)
- Количество доступных заказов [УТВЕРЖДЕНО 2026-09-16; в v0.1 скрыто — заказов нет]
- Текущий заказ: пассажир, пункт Б, таймер/условия мини-задания — крупно в бортовом
  компьютере (TAB), не в постоянном HUD [обновлено 2026-09-16]
- Миникарта в углу (постоянно)
- Пунктир прогноза траектории

### Посадочная индикация [УТВЕРЖДЕНО — есть в ТП]

Индикация посадочного режима: скорость касания (безопасно/опасно), вектор,
статус автопилота. Конкретный вид [ПРЕДЛОЖЕНО]: цветной маркер скорости у планеты
(зелёный < 38, жёлтый до ~55, красный выше) + шкала тяги ×3.2.

### Миникарта [УТВЕРЖДЕНО 2026-09-16 — суть]

- Круглая, правый верхний угол, локальный фрагмент вокруг корабля (весь мир НЕ влезает),
  реальное время
- Планеты и звёзды — уменьшенные реальные (не условные значки), у всего обводка
- Обводка планеты настраиваемая + возможность подсветки жёлтым (цель/выбор)
- Подпись «карта · TAB» не нужна. Параметры и вёрстка — `10_UI_DESIGN.md` §4

## 3. Бортовой компьютер [УТВЕРЖДЕНО — поведение обновлено 2026-09-16]

Панель, выезжающая слева (~480px), главный канал сюжета и заказов (см. `02_STORY.md` §8).
Состав секций (сверху вниз): состояние системы и ракеты; текущий заказ крупно (фото
заказчика, пункт назначения, пожелания; без текущего — входящие заказы); монолог
с фото говорящего (диалогов нет — один говорящий); деньги; рейтинг таксиста;
внизу музыкальный плеер с переключением треков.

Поведение [УТВЕРЖДЕНО 2026-09-16]:
- Открытие: TAB (тумблер); автоматически при открытии карты (M) и паузы (ESC)
- Мир НЕ сдвигается, паузы НЕТ, слоу-мо НЕТ — полёт продолжается
- Не перекрывает миникарту (та справа сверху) и HUD-блок (низ-центр)

Детали вёрстки и спецификация — `10_UI_DESIGN.md` §5.

## 4. Экраны [УТВЕРЖДЕНО — состав, обновлено 2026-09-16]

| Экран | Назначение |
|---|---|
| Меню | старт забега; «Продолжить» без сейва НЕ существует [2026-09-16] |
| Карта системы (M) | вся система с именами планет; пауза; клик по телу → карточка в борт. компьютере (TAB до 2026-09-16 был картой) |
| Пауза (ESC) | пауза + борт. компьютер слева + меню паузы справа (продолжить/настройки/карта/выход) [2026-09-16] |
| Станция | заправка, ремонт, магазин кораблей и улучшений |
| Завершение заказа | разбивка оплаты (дальность/опасность/качество) |
| Авария/гибель | последствия (долг/потеря корабля) |
| Увольнение | экран проигрыша |
| Финал | выход из галактики, победа |

## 5. Камера [УТВЕРЖДЕНО — из ТП; дополнено 2026-09-16]

Камера следования за кораблём + режим обзора (M, зум-аут на всю систему).
Плавный зум [ПРЕДЛОЖЕНО]: лёгкое отдаление при росте скорости для читаемости.
При открытии бортового компьютера/панелей камера НЕ сдвигается [УТВЕРЖДЕНО 2026-09-16].

## 6. Цветовая палитра [ПРЕДЛОЖЕНО]

> **UI [2026-09-20]:** стиль — ретро-зелёный терминал («фосфор»): текст #A8FFCB/#5BC98F,
> заливки #3CFF8E, прямоугольные панели #08140C с рамкой #3CFF8E, JetBrains Mono, шрифт TMP.
> Жёлтый #FFD44D — код игры (чекеры/оплата/цель), danger #FF7A5C. Полные токены — `10_UI_DESIGN.md` §1.

- Фон: глубокий чёрно-синий
- Акцент корпорации/такси: жёлтый + чёрные чекеры (визуальный код игры)
- Планеты: тёплые природные оттенки по секторам (ближние — зелёно-голубые,
  дальние — багровые/ледяные)
- Опасность (жар, дыры, пояса): красно-оранжевые сигналы
- HUD: светлый моноширинный шрифт (бортовой терминал), TextMeshPro [УТВЕРЖДЕНО — TMP]
