## 1. Физика полёта [УТВЕРЖДЕНО]

- Ньютоновская гравитация от всех тел системы одновременно, закон обратных квадратов
- Гравитация меняет и скорость, и направление полёта
- С выключенным двигателем корабль летит дальше без замедления
  (в текстах НЕ писать «по инерции»)
- Пустой бак вдали от планет = потерянный корабль

## 2. Посадка и взлёт [УТВЕРЖДЕНО]

- Посадка возможна в любую точку планеты
- Посадочный режим: ближе r+90 от центра — тяга двигателей ×3.2 (точное управление).
  Автопилот орбиты/циркуляция УДАЛЕНЫ (решение 2026-09-13): рядом с планетой работает
  только ньютоновская физика, «плавной циркуляции» при отпущенных клавишах нет —
  слабая скорость даёт вытянутый эллипс с падением к поверхности
- Контакт с поверхностью: v < 75 → посадка (LandSpeed, Н7); иначе урон
  `0.0022 × (v − 75)²` — квадратичный рост без капа и без ступени min(5):
  бытовые касания прощает, лоб на MaxV смертелен любому корпусу
  (Яйцо@330 = 143 > 100 HP, Барин@485 = 370 > 190 HP; k 0.0022 — Н8.0,
  `22_BALANCE_REWORK.md` §1.5); выживший удар сразу считается посадкой
- HP ≤ 0 → гибель корабля
- Взлёт: ПРОБЕЛ со стоянки, импульс 85 от центра планеты
- Сложность посадки зависит от массы планеты (крупная = сильнее тянет)

## 3. Опасности мира [УТВЕРЖДЕНО]

| Объект | Механика |
|---|---|
| Звёзды | сильное притяжение (×4.5); жаровая зона — поле `HeatRadius` из данных уровня (BetaMap01: 150–209 при r 64–70), урон `k × 30 HP/с × жар-защита корпуса`, k = близость к поверхности; касание звезды — мгновенная гибель |
| Чёрные дыры | воронка v3 (`22_BALANCE_REWORK.md` §1.6, разбор — `15_MECHANICS_DEEP_DIVE.md` §17): притяжение Lerp(45..300, depth²) в зоне эффекта r×6, захват на min(кольцо, зона) с гистерезисом 1.06 — радиальный вылет гасится, орбита закручивается, корабль медленно сжимается (спагетти); гибель по порогу масштаба 0.25 или приближения 45 над горизонтом; вырваться может корабль с тягой выше притяжения ×1.15 (стоковый Барин — да; Игла/Дельта — с двигателем ур.3). Поле общего притяжения дыры ослаблено ×0.03 (настоящее — воронка); после гибели в захвате WreckSystem оставляет обломок кружить у дыры |
| Пояса астероидов | движущиеся астероиды, урон как от планеты: `0.0022 × (v − 75)²` |
| Кометы | быстро пролетают систему, видны издалека; опасность + зрелище; используются в мини-заданиях («пролететь мимо кометы»); маршруты не покидают кометную зону уровня (BetaMap01: (0,0) r 2600) |

В прототипе нереализованы: чёрные дыры, кометы — в Unity-версии делаем.

## 4. Заказы [УТВЕРЖДЕНО]

- Цикл: взять заказ → сесть на планету А (забрать 🙋) → доставить на планету Б (🏠)
- Оплата = дальность + опасность маршрута + качество доставки
- Качество = отсутствие столкновений + выполнение мини-задания + время заказа
- Пассажиры генерируемые: пул имён, фамилий, заданий, рандомный скин (подробнее `02_STORY.md`)

### Мини-задания (3 типа) [УТВЕРЖДЕНО]

| Тип | Примеры |
|---|---|
| Условия полёта | «не любит запах топлива» → без заправок в пути; не превышать крейсерскую скорость; ни одного столкновения |
| Точки интереса | «пролететь мимо кометы»; облететь определённую планету/звезду; зайти с теневой стороны |
| Дедлайны | «торопится» → уложиться в срок; бонус за досрочную доставку |

Манёвровые испытания (идеальная посадка и т.п.) — ОТКЛОНЕНЫ, не делаем.

### Формула оплаты [УТВЕРЖДЕНО 2026-11-13 — тарифные классы; `22_BALANCE_REWORK.md` §1]

```
цена = (посадка_класса + ставка_класса × d_смягч) × множитель_сектора_назначения
       d_смягч = min(d, 2800) + 0.4 × max(0, d − 2800)
       классы: эконом 15+0.16/юн · комфорт 30+0.24 · комфорт+ 55+0.36 · бизнес 90+0.54
       секторы: ХАБ 1.0 / БЛИЖНИЙ 1.15 / МИД-1 1.35 / МИД-2 1.6 / ДАЛЬНИЙ 2.0
класс заказа = класс пассажира сектора назначения (жёсткий фильтр; ~20% нетребовательных)
выплата = цена − штраф_столкновения (−15%/шт, кап −45%) − комиссия аренды (35%) + чаевые (10–25%)
```

Штрафы происшествий (Н7 Q7.5, списание — кошелёк, недостача — в долг):
смерть пассажира (гибель корпуса/отключение с пассажиром) — **−300 кр сверх
долга**; разбитый арендный — **долг +400**; отмена заказа оператором — **−25%
цены**. Долг гасится: 50% с каждой выплаты + кнопка «ПОГАСИТЬ» в борткомпе
(и «ПОГАСИТЬ ДОСРОЧНО» на станции). Порог увольнения: долг **> 2000** (из
PricingConfig) или **3 аварии** с непогашенными долгами (`PricingConfig.cs`).

Классы кораблей: эконом = Скрепка, Яйцо (+аренда) · комфорт = Стрела/Кабан/Дельта ·
комфорт+ = Игла/Меридиан · бизнес = Барин. Модель 2026-11-04 (база+кап+престиж тира) ОТМЕНЕНА.

## 7. Финальный маршрут («босс») [УТВЕРЖДЕНО]

- Доступ: только лучший корабль + полная прокачка
- Игрок летит ЛИЧНО (не дистанционно) — авария = поражение
- Структура (комбо, два акта):
  1. **Дальняя цепочка**: длинная последовательность планет без станций — жёсткий
     расчёт топлива, без права на ошибку
  2. **Коридор**: проход мимо чёрной дыры (и звёзд) по узкому безопасному коридору
     к точке «выхода из галактики»
- Успех = концовка: герой вылетает из галактики домой

## 10. Сложность [ПРЕДЛОЖЕНО]

Сложность рождается из географии, а не из множителей: ближние сектора спокойные,
дальние — пояса, жаровые зоны, чёрные дыры. Плюс экономическое давление:
долги растут → рискованнее заказы нужны. Отдельного переключателя сложности нет.
