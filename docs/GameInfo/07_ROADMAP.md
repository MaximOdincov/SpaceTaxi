1. Этап не закрывается при открытых ошибках/крэшах
2. Каждый закрытый этап = коммит git + пометка здесь (дата)
3. Балансные числа после правок фиксируются в `01_MECHANICS.md` (источник истины — доки, не код)
4. Если в процессе вскрылось设计-решение — оно сначала в док ([ПРЕДЛОЖЕНО] → согласование → [УТВЕРЖДЕНО]), потом в код
