# 17 — БЕТА: реестр задач и брифы

Мелкие задачи для реализации (одна задача = одна механика/экран). Брифы
самодостаточные: копируются исполнителю (маленькая модель / субагент) целиком.
Полный план порций и зависимостей — `16_BETA_PLAN.md` §7; баланс-числа — §3.

**Процесс (напоминание):**
1. Координатор выдаёт бриф задачи → исполнитель работает в ветке
   `agent/beta-<slug>` от `feature/beta` (worktree — если параллельно).
2. После порции (2–4 задачи): ревью диффа большой моделью → правки P0/P1 →
   merge в `feature/beta` → мини-плейтест владельца.
3. Исполнитель НЕ мержит сам, НЕ трогает доки GameInfo, НЕ меняет баланс-числа
   (они в брифе).

## Бриф П1.1 — Кошелёк: кредиты (slug: `wallet`)

**Контекст-блок — вставить первым (см. выше).**

```text
ЗАДАЧА: ввести единый ресурс «кредиты (кр)» и показать его на бортовом
компьютере. Это первая задача экономики беты — пока БЕЗ списаний за топливо,
без оплаты заказов (придут другими задачами).

ЧТО СДЕЛАТЬ:
1. Новая папка Assets/Scripts/Economy/ (в asmdef уже входит — проверить
   SpaceTaxi.Gameplay.asmdef включает все подпапки Scripts).
2. Класс Wallet — plain C# (не MonoBehaviour): баланс int, событие
   event Action<int> CreditsChanged, методы: Add(int), TrySpend(int) → bool,
   свойство Credits. Баланс не может уйти в минус.
3. Владелец Wallet — GameSession (создаётся в Awake, публичное свойство
   только для чтения). Стартовый баланс = 0.
4. UI: OnboardBinder уже биндит moneyValue (текст кредита в секции
   «экономика» бортового компьютера), но значение никогда не присваивается.
   Подписать OnboardBinder на Wallet.CreditsChanged и выводить число +
   суффикс « кр» (формат целого, без дробей).
5. Для проверки работоспособности (временно, пометить комментарием
   «временно, до П4»): кнопка «СМЕНА» на бортовом компе начисляет +100 кр —
   чтобы плейтест увидел живое число. В П4 это уберут.

ЧТО НЕ ДЕЛАТЬ: не трогать OrderService, цены, топливо; не делать сейвы;
не добавлять UI-экраны; не менять ассеты уровней.

КРИТЕРИИ ГОТОВНОСТИ:
- Компиляция без ошибок.
- В игре: бортовой компьютер (TAB) → секция экономики показывает «0 кр».
- Временная кнопка «СМЕНА» увеличивает число на 100, UI обновляется сразу.
- Код в ветке agent/beta-wallet, один-два аккуратных коммита.
```
