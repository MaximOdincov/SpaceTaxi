# 02 — СЮЖЕТ, СЕТТИНГ, ПЕРСОНАЖИ

Завязка утверждена. Этот документ — про подачу: персонажи, тексты, диалоги, тон.
В техпредложение сюжетные детали НЕ пишутся (только для понимания разработкой).

---

## 1. Завязка [УТВЕРЖДЕНО]

Герой случайно попал в систему и разбил свой корабль на планете крупной таксистской
корпорации. Корабли корпорации — беспилотные, управляются дистанционно операторами.
Герой устраивается оператором-таксистом и копит на возвращение домой.

## 2. Цель и финал [УТВЕРЖДЕНО]

- Цель: заработать на лучший корабль, прокачать до максимума, пройти сложный
  длинный маршрут и вылететь из галактики домой
- На финальном маршруте игрок летит ЛИЧНО (не дистанционно) — авария = поражение
- Финал: герой улетает из галактики домой (концовка-«выход»)

## 3. Тон [ПРЕДЛОЖЕНО]

Лёгкая фантастика с мягким юмором «таксистской» темы: чекеры, шашка, въедливые
пассажиры, корпоративная бюрократия в репликах диспетчера. Без мрачности и хоррора.

---

## 4. Корпорация [УТВЕРЖДЕНО: крупная таксистская корпорация; название — открытый вопрос]

Корпорация — работодатель героя и владелец всех арендных кораблей. Присутствует
в игре через: аренду, комиссию, долги, экран увольнения, реплики диспетчера.

### Название корпорации [ОТКРЫТЫЙ ВОПРОС — варианты]

1. «ГалаТакси» — просто и понятно
2. «ОРБИТА-ТАКСИ» — перекликается с названием прототипа
3. «Междузвёздное таксомоторное объединение» (МТО) — бюрократично-смешно

### Диспетчер корпорации [ПРЕДЛОЖЕНО]

Голос корпорации на бортовом компьютере: выдаёт заказы, напоминает о долгах,
«сочувствует» при авариях казёнными фразами. Идеальный канал юмора и подачи правил
(3 аварии, комиссия и т.д.) без обучающих экранов.

---

## 5. Герой [УТВЕРЖДЕНО: оператор-таксист; имя — открытый вопрос]

Герой не показывается на экране (дистанционное управление) — он существует только
в текстах бортового компьютера. [ОТКРЫТЫЙ ВОПРОС] имя героя или безымянный «оператор»?

Варианты имени: Макс / Артём / без имени («Оператор 7-13» — номер вместо имени,
подчёркивает позицию героя в корпорации).

---

## 6. Пассажиры — генерируемые [УТВЕРЖДЕНО]

Механика: пара генерируемых архетипов персонажей, у каждого пул имён, фамилий
и заданий. Рандомно подставляются под скины (визуальные вариации).

### Архетипы [ПРЕДЛОЖЕНО — согласовать]

| Архетип | Характер | Типичные мини-задания |
|---|---|---|
| «Торопыга» | вечно спешит, раздражён | дедлайны |
| «Барыга» | считает каждую единицу ресурса | условия полёта (без заправок) |
| «Турист» | первый раз в системе, всё фотографирует | точки интереса (мимо кометы) |
| «Тихоня» | боится полётов | условия полёта (без столкновений, не выше скорости) |
| «Чудик» | странные просьбы | точки интереса (облететь планету с теневой стороны) |

### Генерация [ПРЕДЛОЖЕНО — структура, согласовать объёмы пулов]

```
Пассажир = архетип (взвешенный рандом)
         + имя (пул 20+) + фамилия (пул 20+)
         + скин (набор спрайтов, рандом)
         + реплика-приветствие (пул по архетипу, 5–8 шт.)
         + мини-задание из пула архетипа (1–2 шт.)
         + реплика-благодарность / жалоба (по результату, 5–8 шт.)
```

Реплики — короткие, 1–2 предложения, живой разговорный тон.

## 8. Подача сюжета [УТВЕРЖДЕНО — канал]

Бортовой компьютер: панель, выезжающая СЛЕВА, с диалогами (диспетчер ↔ оператор,
пассажир ↔ оператор). Все сюжетные события проходят через него:
заказы, взлёт/посадка, аварии, долги, предупреждения, финальный маршрут
(см. `04_GRAPHICS_UI.md`).

### Сюжетные вехи внутри забега [ПРЕДЛОЖЕНО]

| Веха | Подача |
|---|---|
| Старт | диспетчер оформляет «устройся на работу», объясняет аренду |
| Первый долг | казённое письмо о взыскании |
| Погашение долгов | счётчик аварий обнулён, «мы в вас верили» |
| Покупка корабля | поздравление + правило «улучшения только на свои» |
| Открытие финального маршрута | тревожное: «эту трассу наши дроны не летают» — переход на ЛИЧНОЕ управление |
| Финал | выход из галактики, титульный экран |

## 9. Хаб-планета [УТВЕРЖДЕНО: жёлтая планета с чекерами — арт уже генерируется]

Стартовая планета корпорации. Промпт для генерации уже выдан (жёлтая планета,
шашечная лента по экватору, светящаяся табличка-шашка, ракеты-такси на орбите,
чёрный фон, 2D game asset, PNG). Используется как учебная зона и символ игры.
Куда встроить в UI (заставка меню / загрузочный экран / фон брифинга) — решим
при сборке графики (`04_GRAPHICS_UI.md`).
