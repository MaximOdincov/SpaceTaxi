Проект всей линейки до генерации: роли, силуэты, «видимая цена», зоны

## 1. Система «видимой цены» — 5 тиров качества

Цена корабля должна считываться глазами ДО чтения ценника. Два рычага:
качество поверхностей и сложность конструкции.

| Тир | Название | Признаки | Кто |
|---|---|---|---|
| Т-1 | Джанк | ржавые пятна, болты-точки, вмятины контура, кривые стыки разнородных панелей, кривой чекер | Скрепка |
| Т-2 | База | чисто и просто: минимум деталей, матовые цвета, утилитарность | Яйцо |
| Т-3 | Средний | ровные панели, накладки/рамки, аккуратный чекер, доп. огни | Стрела, Кабан, Дельта |
| Т-4 | Высокий | гладкие обтекаемые формы, тонкие полосы, стыки «в стык», без визуального мусора | Игла, Меридиан |
| Т-5 | Люкс | белые глянцевые панели поверх тёмного, золотые линии, многосекционность, неоновые ходовые огни | Барин |

Ржавчина — ТОЛЬКО Т-1. Глянец — с Т-4. Растущая сложность = больше секций.

## 3. Карточки моделей

### №1 «Яйцо» (С1 «Стандарт») — база [АЛЬФА]

- **Конструкция:** яйцо-капсула (ширина ≈ высоте), тупой верх, широкая полоса
  лобового окна, два боковых дуза-«подушки», короткое нижнее сопло
- **Цена-тир Т-2:** простые формы, ноль декора — «казённое новое»
- **Зоны перекраски:** корпус, боковые дузы, окантовка окна, номерная
  табличка-бланк (зона индивидуализации: цвет + номер борта накладывается
  в редакторе)
- **Чекер:** 2 ряда по самой широкой части. **Шашка:** ДА (аренда, оверлей)
- Промпт П1 уже выдан (`13_ART_STYLE.md` §10)

### №2 «Стрела» — быстрый/мощный

- **Конструкция:** пулевидный корпус, 3–4 длинных узких плавника,
  удлинённое сопло, стреловидные боковые дюзы; за основу брать Т1/Т2
- **Цена-тир Т-3:** рамка окна, накладные панели, второй ряд огней
- **Зоны:** плавники, носовой конус, панель у сопла
- **Чекер:** ниже окна. **Шашка:** нет (куплен) / опция аренды старших операторов

### №3 «Кабан» — тяжёлый бронированный заправщик

- **Конструкция:** приземистая широкая баржа, тупая «морда», накладные
  бронеплиты в 2 слоя, ДВА внешних топливных бака-цилиндра по бокам,
  окно-бойница, широкий раструб сопла
- **Статы глазами:** баки = топливо, плиты = броня, squat = медленный
- **Цена-тир Т-3 (промышленный):** заклёпки-точки, аккуратный функциональный
  металл, БЕЗ ржавчины
- **Зоны:** бронеплиты, баки, лобовая пластина
- **Чекер:** на лобовой пластине («бампер»)

### №4 «Дельта» — сбалансированный универсал

- **Конструкция:** широкий плоский КЛИН (оммаж треугольнику прототипа v0.1),
  кабина-пузырь у передней кромки, два движка по углам хвоста
- **Цена-тир Т-3:** чистые линии, тонкие панельные швы
- **Зоны:** плоскость клина, кромки, гондолы движков
- **Чекер:** вдоль задней кромки крыла

### №5 «Игла» — гоночный, максимальная скорость

- **Конструкция:** длинная тонкая игла, миниатюрная кабина-пузырь вверху,
  ОГРОМНОЕ кольцо-движок внизу (шире корпуса), антикрыло-стабилизатор
- **Статы глазами:** корпус-щепка + гигантский движок = «быстро и хрупко»
- **Цена-тир Т-4 (спорт):** светлый корпус, тонкие полосы-штрихи, лёгкий
  глянец тоном
- **Зоны:** корпус-игла, кольцо движка, антикрыло
- **Чекер:** тонкая лента у кабины

### №6 «Скрепка» — самодельный, дешевле базы [Джанк-юмор]

- **Конструкция:** асимметричный корпус из разнородных кусков: бак-бочка +
  ящик-отсек + причудливая кабина, сопла РАЗНОГО размера, самодельный плавник,
  антенна с банкой, изолента-полоски
- **Статы глазами:** всё маленькое, кривое и печальное — хуже «Яйца»
- **Цена-тир Т-1:** ржавые пятна, болты, вмятины контура, панели в разных
  цветах, ЧЕКЕР НАКЛЕЕН КРИВО (местами облупился) — главная шутка
- **Зоны:** бочка, ящик-отсек, плавник (каждый кусок красится отдельно)
- **Чекер:** кривой. **Шашка:** нет (собран в гараже)

### №7 «Меридиан» — комфорт-класс, баланс+

- **Конструкция:** вытянутый гладкий овал-фюзеляж со «спиной»-гребнем,
  два стреловидных крыла-дуги, спаренные движки в едином блоке
- **Отличие от «Дельты» (та же ниша, класс выше):** не клин, а пузатый овал;
  плавнее, длиннее, дороже на вид; Дельта = «рабочая», Меридиан = «личная»
- **Цена-тир Т-4:** идеальные стыки, тонкая белая полоса вдоль корпуса
- **Зоны:** фюзеляж, крылья-дуги, движковый блок
- **Чекер:** аккуратная тонкая лента на хвосте

### №8 «Барин» — флагман, финальный маршрут [ЛЮКС]

- **Конструкция:** большой трёхсекционный лайнер: нос-свод (капитанский),
  широкая середина с панорамной полосой окна, корма с ТРЕМЯ соплами в ряд,
  хвостовые плавники дугой, штырёк-антенна
- **Лор:** единственный корабль, способный пройти финальный маршрут
  (`02_STORY.md` §2) — покупка = конецгейм
- **Цена-тир Т-5:** белые глянцевые панели поверх графита, золотые линии,
  зелёные неоновые ходовые огни
- **Зоны:** нос, боковые панели, сопла; золотые линии
- **Чекер:** ЗОЛОТОЙ (золото+чёрный) на борту — премиальный вариант кода

## 4. Персонализация: правила зон перекраски

Требование: элементы, правящиеся в Figma/Photoshop без перекраски соседнего.

1. Каждая зона = ЗАМКНУТАЯ область одного плоского цвета; зоны одного
   назначения (все плавники) — один цвет
2. Полутон — отдельный полумесяц справа (2 тона, §0 п.13 `13_ART_STYLE.md`);
   при перекраске красить аналогично (затемнение −20% от нового цвета) либо
   не трогать; падающих теней нет нигде
3. Цвета зон контрастны к соседним областям — заливка «по пикселю»
   (Figma: select same fill / PS: magic wand, tolerance 10–20, contiguous)
4. Карта зон у каждой модели — в карточке §3; полосы/чекер/шашка не красятся
   (это код игры), кроме золота «Барина»
5. Зоны частично повторяются между моделями (полоса, плавники), большинство
   уникальны (баки «Кабана», кольцо «Иглы», панели «Барина», табличка «Яйца»)

## 5. Инварианты всех кораблей

- Вертикально, нос строго вверх, квадрат 512×512, экспорт PPU 32
  (длина 12–16 юнитов: Игла 16, Кабан 10×13, Барин 15, остальные ~14 —
  финальные размеры согласует левел/программист)
- Стиль-якорь `13_ART_STYLE.md` §2 без исключений (2 тона: база + полутон
  справа; без контуров и падающих теней — §0 п.13)
- Выхлоп не печём (частицы в Unity), сопла без огня
- Чекер-код: у всех, качество по тиру (кривой у Скрепки, золотой у Барина)
- Шашка-оверлей ТОЛЬКО на аренде (`ship_shashka.png`)
