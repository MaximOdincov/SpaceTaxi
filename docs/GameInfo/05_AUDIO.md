## 0. Характер звука (стиль)

Единый образ: **аналоговый синтез, кабина, терминал** — созвучно жёлто-чёрным
чекерам и моноширинному HUD. Принципы подбора:

- Двигатели — мягкий низкий гул, «такси, а не истребитель»; тон чуть растёт со скоростью
- UI — короткие терминальные клики и пинги, без «пиксельной» резкости
- Столкновения — глухие удары корпуса (не взрывы), громкость от силы
- Непрерывные звуки нарастают/затухают плавно (~0.15 с) — без щелчков

## 2. Музыка [РЕШЕНО 2026-09-13; основная тема обновлена 2026-09-15]

Решение (закрыт открытый вопрос #6): **эмбиент + 2 трека** — меню и полёт.

- **Полёт: Magic Space (CodeManu, CC0)** — светлая, воодушевляющая sci-fi-тема.
  Прежняя «My Very Own Dead Ship» была слишком удручающей — перенесена

- Эмбиент — тихий слой «кабины» под музыкой (производный: engine-луп с pitch 0.45
  и громкостью 0.16; можно заменить отдельным файлом без правок кода)
- **Плейлист-задел (внутриигровой плеер, полная версия):** 11 CC0-треков разных жанров
  в `Assets/Audio/Music/Candidates/` (theme_01..11): светлый эмбиент, чиптюн-лайт,
  босса-нова/лаунж, elevator-джаз, synthwave, электроника+метал, рок/метал,

  игроку менять тему полёта; состав расширяется простым добавлением файлов

## 3. Архитектура [УТВЕРЖДЕНО; реализовано в v0.1]

Принципы (были утверждены ранее):
- Центральный `AudioManager` (не рассыпанные AudioSource по сцене)
- Вызовы через события-идентификаторы: `Sound.Play(SoundId.Takeoff)`
- Непрерывные звуки — управляемые параметры, не one-shot
- Громкости групп: движки / эффекты / UI / музыка — раздельные ползунки (структура
  готова; в v0.1 в настройках общий Master, раздельные — когда появится экран настроек)
- Источники звуков подключаются заменой ассета, без правок кода вызовов

Реализация (`Assets/Scripts/Audio/`, namespace `SpaceTaxi.Audio`, сборка SpaceTaxi.Gameplay):

| Класс | Ответственность |
|---|---|
| `SoundId`, `AudioGroup` | enum'ы: события и группы громкости (Engine/Sfx/Ui/Music) |
| `SoundEntry` | [Serializable]: клипы-вариации, группа, громкость, pitch, разброс тона, loop |
| `AudioCatalog` (SO) | соответствие «событие → клипы и параметры микса»; ассет `Assets/ScriptableObjects/AudioCatalog.asset` |
| `AudioManager` | singleton, DontDestroyOnLoad; пул one-shot, голоса лупов, кроссфейд музыки, громкости групп (PlayerPrefs), ducking при взрыве |
| `Sound` | статический фасад: `Sound.Play / SetLoop / SetLoopIntensity / SetLoopPan / PlayMusic` — вызовы из любого кода |
| `ShipAudio` | на корабле: двигатели по вводу W/S/A/D, панорама стрейфа, посадка/удар по жёсткости контакта, взлёт, гибель, респавн |
| `HeatAudio` | на корабле: гул жара по близости к ближайшей звезде |
| `SceneMusic` | на сцене: музыка + эмбиент (меню: MusicMenu без эмбиента; игра: MusicFlight + эмбиент) |

Ключевое поведение:
- Лупы: fade-in/out 0.15 с; интенсивность 0..1 → громкость 0.4–1.0 и pitch 0.9–1.12
- One-shot: случайная вариация + разброс тона (±4%, у ударов ±8%) — «живость»
- Collision: 3 клипа по возрастанию силы, выбираются по интенсивности удара
- Взрыв: приглушение групп Engine/Sfx до 0.2 с возвратом за 1.2 с («срез»)
- Громкость групп: линейный множитель; Master — через AudioListener.volume (квадратичная
  кривая для ровного ощущения ползунка); сохранение в PlayerPrefs («audio.vol.*»)
- Микшер Unity не используется в v0.1 (громкости кодом); при необходимости DSP — позже

Hook-точки интеграции (что уже подключено / что ждать):
- `ShipAudio.OnCollisionEnter2D` приходит вместе с `LandingSystem` — звук по скорости
  контакта относительно LAND_SPEED; когда программист реализует посадку/урон (задача 3),
  логика звука не меняется
- `ShipAudio` поллит `Ship.Hp/State` — взрыв/респавн заработают автоматически с задачей 5
- `ShipAudio`/`HeatAudio` вешаются на префаб/объект корабля (в GameScene корабля пока нет —
  добавит WorldBuilder/программист: компоненты + `input` = GameInput)
- MainMenu/SettingsMenu (задача 7): на клики — `Sound.Play(SoundId.UiClick)`,
  ползунок громкости — `AudioManager.Instance.SetMasterVolume(v)`
- OnboardComputer (задача 8): на новое сообщение — `Sound.Play(SoundId.ComputerPing)`
