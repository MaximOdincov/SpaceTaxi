## Ключевые решения (сводка, всё [УТВЕРЖДЕНО])

1. Физика ньютоновская: гравитация всех тел одновременно, свой закон обратных квадратов поверх Rigidbody2D. С выключенным двигателем корабль летит дальше без замедления
2. Управление: W — разгон по курсу, S — тормоз, A/D — боковая тяга, TAB — бортовой компьютер, M — карта системы, миникарта, пунктир прогноза траектории (разгон перенесён с ПРОБЕЛА на W, 2026-09-12; TAB/M переназначены 2026-09-16 — ранее TAB открывал карту)
3. Мир: фиксированная (авторская) большая карта — 20+ планет, 4+ звёзд, чёрные дыры, пояса астероидов, кометы, станции на части планет
4. Заказы: забрать пассажира на планете А → доставить на Б. Оплата = дальность + опасность + качество
5. Качество = отсутствие столкновений + выполнение мини-задания + время заказа
6. Мини-задания трёх типов: условия полёта, точки интереса, дедлайны
7. Единый ресурс (не «деньги»): тратится на топливо, ремонт, улучшения, покупку кораблей, долги
8. Аренда с комиссией, 3 аварии с долгами = увольнение = проигрыш; свой разбитый корабль = потеря машины и улучшений; улучшения только на купленные корабли
9. Кораблей 8, с глубокой прогрессией (линейка утверждена 2026-11-04 — `16_BETA_PLAN.md` §3.3)
10. Финальный маршрут (личный полёт, авария = проигрыш): комбо — дальняя цепочка планет без станций, затем коридор мимо чёрной дыры к точке выхода
11. Пассажиры: генерируемые (пулы имён, фамилий, заданий) под рандомные скины + позже специальные прописанные персонажи
12. Между игровыми сессиями не сохранается НИЧЕТО (ни прогресс, ни статистика, ни рекорды) — УСТАРЕЛО 2026-09-12, актуально: автосейв при выходе в меню/из игры, «Продолжить» в меню (см. `01_MECHANICS.md` §9)
13. Звук закладывается в архитектуру сразу, полный набор
14. Процесс сборки сцены: гибрид (логика кодом, часть сборки руками в редакторе по инструкциям)
15. Графика на старте: простые заглушки, генерируемые кодом (круглые планеты, треугольная ракета)

## Правила работы

- Статусные пометки в доках обязательны. Изменение [УТВЕРЖДЕНО]-блока — только после явного согласования
- Тексты для техпредложения (для преподавателя) пишутся отдельно, «человеческим» стилем — критично: простые фразы, без emoji, без списков в основном тексте. Внутренние доки GameInfo — обычный стиль
- Изменения в доках фиксируются по ходу работы (я — координатор, актуальность доков важнее всего)
- **Unity CLI (установлен, `~/.unity/bin/unity`, v1.0.0-beta.9)** — прямой канал к живому редактору.
  РАЗДЕЛЕНИЕ РОЛЕЙ [УТВЕРЖДЕНО 2026-09-12]: агент сам пишет код, компилирует, проверяет ошибки
  (компиляция/импорт/логи) и применяет изменения в сцену. Play Mode и проверку геймплея запускает
  ТОЛЬКО пользователь — агент НЕ включает Play Mode сам. Скриншоты не использовать как способ
  проверки. Детали и приёмы: `06_TECH_ARCHITECTURE.md` §9
- **Плагин unity-agent-plugin (Unity Technologies) установлен в ZCode** — скиллы лучших практик
  Unity (CLI, URP, TextMeshPro, UI, спрайты, аудио и др.), подхватываются в новых сессиях
- Баланс: числа прототипа (THRUST=95, RETRO=115, MAXV=330, STRAFE_ACC=85, FUEL_MAX=100, HP_MAX=100, LAND_SPEED=38, TAKEOFF_V=85, ENG_MUL=3.2 и др.) — отправная точка, полный список в `01_MECHANICS.md`
