и план работ беты; он же критерий приёмки.

### 3.5 Ценообразование заказов [ПРЕДЛОЖЕНО — модель владельца 2026-11-04]

Модель: диспетчер заранее предлагает ФИКСИРОВАННУЮ цену на карточке заказа.
Аккуратная доставка без столкновений подразумевается по умолчанию — столкновения
это ШТРАФ от цены. Срок и задания существуют только если заданы пассажиром —
это ЧАЕВЫЕ сверх цены, их размер определяется характером пассажира (архетип)
и классом района назначения.

```
ЦЕНА ПРЕДЛОЖЕНИЯ (видна на карточке заранее):
  цена = (база + дальность_эфф × 0.25) × класс_сектора_назначения
  дальность_эфф = min(дальность, 1500)          — кап: заказ «через всю карту»
                                                  не делает богатым
  класс сектора: ХАБ/БЛИЖНИЙ 1.0, СРЕДНИЙ-1 1.3, СРЕДНИЙ-2 1.6, ДАЛЬНИЙ 2.0
  (класс сектора ПЛАНЕТЫ НАЗНАЧЕНИЯ — куда везём пассажира)

ВЫПЛАТА (экран завершения заказа):
  выплата = цена − штраф_столкновения − комиссия + чаевые
  штраф: −15% от цены за каждое столкновение (урон корпуса от контакта;
         жар звезды не считается), кап −45%
  комиссия аренды: −25% от (цена − штраф), только на арендном корабле
  чаевые: только при выполненном задании пассажира (§3.6):
          чаевые = цена × щедрость_архетипа (10–25%)
          перк «Меридиана» +10% к чаевым
```

Примеры (проверка математики):
- Ближний, 500 юн: цена (40+125)·1.0 = 165 кр; без инцидентов = 165 кр
- Средний-2, 1400 юн: (40+350)·1.6 = 624 кр; чаевые Туриста +20% = 125 кр
- Дальний, 4000 юн (кап 1500): (40+375)·2.0 = 830 кр — потолок одного заказа,
  «Скрепка» (900) недостижима за один заказ, «Яйцо» (1500) = 2–3 заказа
- Аренда, 2 столкновения: 624 → −30% = 437 → −25% = 327 кр на руки

Ориентиры из 01 §5 («ближние 80–150, дальние 300–500») устарели для этой
модели; контрольная цифра одна: забег от аренды до «Барина» + полная прокачка
(22 000 кр) = 25–40 доставок. Сверка фактических цен по секторам — приёмка
BetaMap (§4).

### 3.6 Задания пассажиров — источник чаевых [ПРЕДЛОЖЕНО]

Универсального таймера на заказ НЕТ. Задание (и, возможно, дедлайн) задаётся
пассажиром: одно на заказ, из пула его архетипа. Выполнил — чаевые из §3.5,
не выполнил — без чаевых и жалоба (минус рейтинг §3.7). На карточке заказа
задание видно сразу (пассажир говорит заранее).

| Архетип | Щедрость | Тип задания | Варианты |
|---|---|---|---|
| Торопыга | 15% | дедлайн | «Опаздываю!» — доставить за T = дальность/150 + 45 с (таймер на карточке активного заказа) |
| Барыга | 10% | условия | «Не заправляемся в пути» — без посадки на станции; «Бережёный груз» — ни одного столкновения (проверка своя, чаевые только при нуле) |
| Турист | 20% | точки интереса | «Покажите комету!» — пролететь в 400 от кометы; «Облетим ту?» — зайти в кольцо планеты X (не А/Б); «С теневой стороны» — пройти за звездой относительно центра |
| Тихоня | 10% | условия | «Тише едем» — скорость ≤ 250 весь полёт с пассажиром; «Без трясок» — без столкновений |
| Чудик | 25% | точки интереса | «Мимо бездны!» — пролететь в 800 от чёрной дыры (не гибнуть); «Посидим перед стартом» — постоять на планете А 10 с |

Вкусовое с AlphaMap (09 §7.6) — «фанат Вима не летит с Эмакса» — на BetaMap
имён нет, НЕ переносим (задел на релиз).

### 3.7 Рейтинг таксиста ★ [ПРЕДЛОЖЕНО — формулы в доках не было]

Шкала 0.0–5.0, шаг 0.1, старт новой игры 3.0. Отображение: бортовой компьютер
(слот уже есть).

| Событие | Δ рейтинга |
|---|---|
| Доставка | +0.15 |
| Столкновение при активном заказе | −0.10 за каждое |
| Задание пассажира выполнено | +0.10 |
| Провал заказа (не гибель) | −0.30 |
| Провал заказа гибелью/потерей корабля | −0.50 |

Влияние [ПРЕДЛОЖЕНО]: рейтинг ≥ 4.0 → +10% к цене предложения («популярного
водителя видно»); рейтинг < 2.0 → карточки заказов появляются на 30% медленнее.
Между 2.0 и 4.0 — без эффектов. Кламп [0.0; 5.0].

### 3.8 Опасности мира: дыры, пояса, кометы [УТВЕРЖДЕНО 2026-11-04 — в бету]

| Объект | Механика | Числа [ПРЕДЛОЖЕНО] |
|---|---|---|
| Чёрная дыра | масса ×8 (сильнее звезды), горизонт = гибель; в зоне захвата корабль МЕДЛЕННО уменьшается (масштаб 1→0 за ~4 с) и исчезает; звук: нарастающий гул → «провал» | горизонт = r; зона эффекта r×6 |
| Пояс астероидов | полоса из N астероидов (круглые тела r 4–10), вращаются вокруг центральной точки пояса (движение!); столкновение = урон как от планеты (v−55)·0.9; тост-предупреждение при входе | N = 24–40, урон кап 30 |
| Кометы | 3 маршрута по таймеру, циклично; летят быстро (v ~400), след частицами, видны издалека; предупреждение на миникарте за 20 с; столкновение = гибель (как звезда) | интервалы 90–150 с |

Прогноз траектории учитывает дыры (гравитация) — прогноз уже общий через
GravityField. Миникарта: показывать предупреждение кометы (стрелка направления).

### 3.9 Сохранения [УТВЕРЖДЕНО схема 2026-09-12; реализация — бета]

Автосейв при выходе в меню/из игры + при завершении заказа. Формат JSON,

иначе затемнена. Кривой/отсутствующий сейв = «Продолжить» неактивно, ошибок нет.

## 4. Карта беты: BigMap01 → BetaMap [ПРЕДЛОЖЕНО]

База — BigMap01 (24 планеты + 4 звезды, черновик готов, генератор
`tools/bigmap01.py`). Доработка (левел-дизайн, сессия С4):

- Сектора как в 03: ХАБ → БЛИЖНИЙ → СРЕДНИЙ-1 → СРЕДНИЙ-2 → ДАЛЬНИЙ.
  «КРАЙ» НЕ строим (релиз).
- Хаб МТО: центральная планета Гавань → жёлтая чекерная, хаб-арт (§5),
  станция корпорации, старт игрока.
- Чёрная дыра №1: зарезервированная точка (−2200, 4600), «соблазн срезать»
  через Средний-2.
- Пояса (2 из 4): зарезервированные Толок→Сито (Средний-1) и Буй→Полынь
  (Средний-2). Два пояса Дальнего сектора — по вкусу левел-дизайнера, если
  сектор «пусто» по опасности.
- Кометы: 2–3 маршрута, южный квадрант (Y < −900), по таймерам.
- Станции: 9 планет из 24 — хаб, 2 ближних, 3+2 средних, Дальний БЕЗ станций
  (ворота прогрессии: большой бак = большие корабли). Проверка: с любой планеты
  сектора ближайшая станция достижима на баке корабля своего сектора.
- WorldRadius: по фактическому размаху карты + запас 1500.
- Запрет из 03 сохраняется: жаровые зоны не ближе 550 от старта.
- Приёмка: таблица заказов по секторам попадает в вилку оплаты из §3.5
  (ближние 80–150 … дальние до 700). Если не попадает — править коэффициент
  дальности формулы (одно число в SO).

AlphaMap01 остаётся тестовым полигоном (в билд не входит).
