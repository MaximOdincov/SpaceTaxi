# 10 — UI-ДИЗАЙН: концепция, макеты, спецификация

Дизайн-проект интерфейса Space Taxi: главный экран-состав (меню, HUD, мини-карта,
бортовой компьютер, карта, пауза), поведение элементов и спецификация для сборки.
Источник решений — сессия UI-дизайнера 2026-09-16 (утверждено координатором в чате).

Связанные доки: `04_GRAPHICS_UI.md` (стиль/палитра — верхний уровень),
`08_PROTOTYPE_V01.md` §6 (бриф UI-дизайнера), `02_STORY.md` §8 (подача сюжета),
`01_MECHANICS.md` §1 (управление).

**Реализация [2026-09-20]: Figma отменена** (OAuth-блокер у MCP; решение координатора).
Весь UI собран **напрямую в Unity-сценах** (GameScene / MainMenu) — состав, скрипты и ассеты
в §10. Ход сборки и хвосты: `.zcode/figma-ui-build-state.md`.

## 0. Ключевые поведенческие решения [УТВЕРЖДЕНО 2026-09-16]

| # | Решение |
|---|---|
| 1 | **TAB — бортовой компьютер**, **M — карта** (ранее TAB был картой — отменено) |
| 2 | Карта (M) открывает бортовой компьютер автоматически (панель слева + карта) |
| 3 | Карта ставит игру на паузу, но показывает актуальное состояние мира |

| 7 | Мини-карта: НЕ весь мир — локальный фрагмент вокруг корабля, реальное время; планеты/звёзды — уменьшенные реальные, не условные значки; у всего обводка |
| 8 | У планеты на мини-карте обводка настраиваемая + возможность подсветки жёлтым (цель/выбор) |
| 9 | Подпись «карта · TAB» на мини-карте НЕ нужна |
| 10 | Меню: кнопки «Продолжить» без сейва НЕ существует (не затемнена — отсутствует); при наличии сейва под кнопкой строка «сессия: дата · планета» |
| 11 | На карте (M): имена планет уже над ними; клик по телу → карточка в бортовом компьютере (картинка, название, масса, расстояние и т.д.); hover — планета слегка увеличивается |
| 12 | ESC: пауза + бортовой компьютер слева + справа меню паузы (продолжить, настройки, карта, выход) |
| 13 | Цвета и шрифты — предварительные, финальный подбор позже (меняем палитру целиком, см. §1) |
| 14 | UI делаем сразу по смыслу финальным, визуальный дизайн может меняться |
| 15 | **Стиль — ретро-зелёный терминал** («фосфор»): прямоугольные панели без скруглений, заливки «панельками» без спрайтов, монохром [2026-09-16..20, по ходу сборки] |
| 16 | **HUD**: кластер слева-сверху; метки → иконки (спидометр/щит/канистра); прочность в %; топливо — горизонтальная **сегментная** шкала (10 сегментов); значения 36px [2026-09-20] |
| 17 | **M не ставит паузу; пауза только ESC.** Из паузы карта открывается с сохранением паузы; закрытие карты возвращает меню паузы; закрытие карты (открытой из игры) гасит и борт.комп [2026-09-20] |
| 18 | «ЗАКАЗЫ: N» на HUD не выводятся (передумали) [2026-09-20] |
| 19 | Экран настроек — префаб, открывается из меню и из паузы; слайдеры громкостей пока без привязки к AudioManager [2026-09-20] |

## 5. Бортовой компьютер (TAB) [УТВЕРЖДЕНО 2026-09-16 — поведение и состав; вёрстка ПРЕДЛОЖЕНО]

**Поведение [утверждено]:**
- Открывается TAB (тумблер), а также автоматически при открытии карты (M) и паузы (ESC)
- Панель выезжает слева с анимацией; ширина ~480px (25% экрана)
- Мир НЕ сдвигается, камера не меняется, паузы НЕТ, слоу-мо НЕТ — полёт продолжается
- Поверх HUD, не перекрывает миникарту (та справа) и HUD-блок (низ-центр)

## 6. Карта (M) [УТВЕРЖДЕНО 2026-09-16 — суть; детали ПРЕДЛОЖЕНО]

**Поведение [утверждено; пауза отменена решением №17]:**
- M — открыть/закрыть; вместе с бортовым компьютером слева (закрытие карты гасит и его)
- **M НЕ ставит паузу** — полёт продолжается; из паузы (кнопка «КАРТА»/M) пауза сохраняется
- Закрытие карты, открытой из паузы, возвращает меню паузы
- Камера — зум-аут на всю систему (fit bounds + отступ, плавный переход) [не реализовано]
- Имена планет — над телами (часть вида карты; в макете — метки UI)
- Hover на планету/звезду — тело слегка увеличивается (scale ~1.15, 0.15с) [не реализовано]
- Клик по телу — выбирает его: жёлтая обводка + карточка тела в бортовом компьютере [не реализовано]

**Построено [2026-09-20]:** `UI_Root/MapScreen` — подложка-панель на зону справа от борт.компа
(1440×1080, заголовок `// КАРТА СИСТЕМЫ`), тела TestLevel01 масштабом 0.5 (Y инвертирован,
сдвиг под панель), имена над телами, жёлтое кольцо-выбор на Мишени, маркер-стрелка корабля
у Гавани, подсказка режима внизу справа. Старт неактивен.

**Карточка тела в бортовом компьютере** (замещает секцию «Текущий заказ» на время карты):

| Поле | Пример |
|---|---|
| Картинка | крупный круг/арт тела 128×128 |
| Название + тип | «Мишень · планета» (звезда: «Печь · звезда») |
| Масса / радиус | множитель массы 1.0 / r = 20 |
| Расстояние | от корабля, юн (обновляется? нет — пауза: значение на момент открытия) |
| Особенности | жаровая зона (для звёзд), станция ⛽, сектор, посещена ли |

Выход из карты: M или ESC. **ESC из карты просто закрывает карту** [ЗАФИКСИРОВАНО 2026-09-20 —
вопрос №3 закрыт]; тем же нажатием ESC пауза не включается (кадровый guard в контроллерах).

## 7. Пауза (ESC) [УТВЕРЖДЕНО 2026-09-16]

```
┌─────────┬────────────────────────────────────┐
│ борт.   │              ПАУЗА                 │
│ компью- │                                   │
│ тер     │         ▸ ПРОДОЛЖИТЬ               │
│ (тот же,│         ▸ КАРТА (M)                │
│ читает- │         ▸ НАСТРОЙКИ                │
│ ся)     │         ▸ ВЫЙТИ В МЕНЮ             │
│         │         ▸ ВЫЙТИ ИЗ ИГРЫ            │
│         │   (мир затемнён 40% + виньетка)    │
└─────────┴────────────────────────────────────┘
```

- ESC — пауза (timeScale=0) + бортовой компьютер слева + меню паузы справа
- Меню паузы: колонка по центру правой зоны, кнопки 360×56 (стиль меню)
- «Продолжить» = ESC; «Карта» — переход в режим карты; «Выйти в меню» — автосейв;
  «Выйти из игры» — автосейв + выход
- Затемнение мира 40% чёрным + виньетка; HUD скрыт [предложено]

**Построено [2026-09-20]:** `UI_Root/PauseScreen` — затемнение 40% (без виньетки), титул «ПАУЗА»,
5 кнопок 360×56 в центре правой зоны. Все кнопки рабочие: ПРОДОЛЖИТЬ (ESC-логика), КАРТА (с
сохранением паузы), НАСТРОЙКИ (прячет меню паузы; НАЗАД возвращает), ВЫЙТИ В МЕНЮ (MainMenu +

Скрипты `Assets/Scripts/UI/`: `OnboardComputerPanel` (TAB, слайд 0.25с ease-out, старт скрыт),
`MapScreenController` (M, без паузы, связка с борт.компом и паузой), `PauseScreenController`
(ESC + timeScale + настройки из паузы), `SettingsScreenController` (Open/Close в префабе),
`SceneFlowButtons` (переходы сцен, выход; в редакторе выход = стоп Play Mode).

Кнопки: hover = штатный ColorTint (зелёное свечение ×2.6/4.2/3.1), клик = `ui_click.ogg`
через AudioSource + persistent onClick; Selected = обычный цвет (не «залипает»).

Клавиши: **TAB** борт.комп · **M** карта (+борт.комп, без паузы) · **ESC** пауза (+борт.комп;
в карте — закрыть карту; из паузы «КАРТА» — с сохранением паузы).

Прочее: EventSystem на новом Input System в обеих сценах; камеры — SolidColor #05060F,
HDR off (было Clear=Nothing → артефакты-полосы); Canvas — Overlay, CanvasScaler 1920×1080 0.5.

**Хвосты (не реализовано):** карточка тела в борт.компе при выборе на карте; hover планет и
зум-аут камеры карты; привязка живых данных (корпус/топливо/скорость/деньги/заказ); привязка
слайдеров настроек к AudioManager + ПРИМЕНИТЬ; пульс жёлтого кольца; гашение HUD при панелях;
настройки — только громкости (схема управления — текстом).
