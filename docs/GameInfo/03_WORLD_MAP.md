Решение [УТВЕРЖДЕНО]: одна большая 2D-карта — мультизвёздная система, без дозагрузок,
фиксированная (авторская, не процедурная).

> v0.1; состав тел и имена сохранены, изменились позиции/радиусы/WorldRadius.

## 0. Текущая карта — `BetaMap01.asset` (M8.4, ночь Н8) [АКТУАЛЬНО]

Граница системы **WorldRadius = 4600** (край тел ~4235, запас ~365; дальше — «ПОТЕРЯНА СВЯЗЬ»).
Хаб в центре, планеты — тремя концентрическими кольцами, звёзды — периферийное кольцо,
пояса — кольца между зонами, кометная зона — внутри мира. Всего 30 тел.

### Правила, зафиксированные при пересборке

- **Правило размера** (решение владельца): визуальный диаметр ЛЮБОЙ планеты ≥ 3×
  диаметра корабля (корабль 44 юн → планета ≥ 132). Выполнено: все 24 планеты
  R_игр 68–90 (Ø 136–180 = ≥ 3.09×); R_игр = Radius × VisualSizeMul (ассет), звёзды/дыры —
  сырой Radius.
- **Правило жара** (2026-11-13, `22_BALANCE_REWORK.md` §1.7): звезда не ближе
  **1400 юн** от хаба (вместо старых 550); по M8.4 — звёзды на r3950, дистанция до старта
  ≥ средней межпланетной дистанции (2870).
- Зазоры/кольца: посадочные кольца r+90, захват ×3.3+30, инварианты K0 violations=0
  (зазоры поверхностей min 694; жар до планет ≥ 1482; зона дыры до планет ≥ 1471).
- Секторы оплаты: ХАБ 1.0 / БЛИЖНИЙ 1.15 / МИД-1 1.35 / МИД-2 1.6 / ДАЛЬНИЙ 2.0
  (`PricingConfig.SectorRequiredClass`: эконом/эконом/комфорт/комфорт+/бизнес —
  престиж-фильтр, ~20% нетребовательных).
- Станции (платные, экран [B]): хаб + Тихая (топл.1/рем.1), Луг (топл.1), Веста (3/3),
  Грань (топл.3), Кузня (рем.2), Полынь (рем.1), Стужа (топл.2), Ворон (топл.4/рем.2);
  Дальний без станций (бак = ворота прогрессии).
- Риск для пейсинга (владельцу): средняя межпланетная дистанция выросла ×1.39
  (1923 → 2822 юн) — рычаг мировой баланс, модель BALANCE_N5 distances пересчитать при следующей сверке.

Полный список тел (позиции/радиусы/множители/услуги/секторы) — источник истины
`Assets/ScriptableObjects/BetaMap01.asset`; редактирование — редактор уровня
«Space Taxi → Level Editor» (`Assets/Editor/LevelEditorWindow.cs`), превью в Scene View
рисует тела по игровым радиусам (CelestialBody.Init).

## 2. Секторы [ИСТОРИЯ — компоновка теперь кольцами, см. §0]

Карта делится на секторы по удалённости от хаба. Сложность растёт с расстоянием —
дальше = опаснее и выгоднее (принцип сложности через географию, `01_MECHANICS.md` §10).

### Назначение секторов

| Сектор | Роль | Заказы |
|---|---|---|
| Хаб | старт, учебная зона, символ игры | первые доставки |
| Ближний | освоение посадки/физики, мягкая экономика | тариф эконом |
| Средний-1 | пояса астероидов, первые опасности | тариф комфорт |
| Средний-2 | чёрная дыра, «опасные» маршруты | тариф комфорт+ |
| Дальний | без станций, жёсткий расчёт топлива | тариф бизнес |

## 4. Опасности на карте

Правило (обновлено 2026-11-13, `22_BALANCE_REWORK.md` §1.7): жаровые зоны звёзд —
не ближе 1400 юн от хаба (ранее 550); по M8.4 звёзды вынесены на периферийное
кольцо r3950 (см. §0).

| Зона | Правило размещения [ИСТОРИЯ] |
|---|---|
| Жаровые зоны звёзд | не ближе 1400 от старта (было 550); звезда рядом с трассой = «опасный» коэф. заказа |
| Чёрная дыра | видна с середины карты, «притягивает» маршруты — соблазн срезать |
| Пояса | между кольцами расселения — выбор: через пояс (быстро, урон) или вокруг (долго, топливо) |
| Кометы | маршруты не покидают кометную зону (BetaMap01: (0,0) r2600); предупреждение на миникарте заранее |

## 5. Именование [УТВЕРЖДЕНО]

Планетам и станциям даются короткие имена/коды (для бортового компьютера и заказов):
ближний — «домашние» имена (Колыбель, Мишень, Тихая...), дальние — коды (М-14, Д-2, Д-4/Бис, К-77, С-9).
Полный список — `BetaMap01.asset`.

---

## 6. Формат хранения карты [УТВЕРЖДЕНО]

Карта описывается данными (ScriptableObject `LevelAsset` + список `CelestialBodyData`
с типом/позицией/радиусом/массой/услугами/визуалом), сцена собирается из данных кодом —
правки карты = правка данных (`Assets/ScriptableObjects/BetaMap01.asset`), а не
перетаскивание объектов в редакторе. Редактор: «Space Taxi → Level Editor».
