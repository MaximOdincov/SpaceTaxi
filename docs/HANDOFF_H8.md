## Как работать (выучить до первых правок)

1. **Редактор гоняет только назначенный агент/сессия**; после каждой плей-проверки —
   `unity command editor.playmode stop` + убедиться `playMode=stopped`. В каждом полле
   `if (EditorApplication.isPaused) EditorApplication.isPaused = false;` (Error Pause
   ловит шум пайплайна).
2. **Сцены/.unity/.prefab руками не править** — только eval/SerializedObject. Внешне
   изменённый .unity → перезагрузить сцену. Сейв пользователя не трогать.
3. **Скриншоты** — `UnityEngine.ScreenCapture.CaptureScreenshot("Temp/…png")` из eval
   (`capture_game_view` врёт без фокуса). Пайплайн `unity command screenshot` может дать
   чёрный кадр при заморозке — ScreenCapture из eval надёжнее, когда цикл жив.
4. **Pipeline eval**: окно ~5с (долгие операции успевают выполниться после таймаута —
   проверь состояние, не повторяй вслепую); колбэки не переживают вызовы CLI;
   детерминированные замеры — в одном eval. Плей-сессия после нескольких рекомпилов
   может замереть на кадре 1 — лечится `unity command editor_pause` toggle или
   перезапуском плей-сессии.
5. **UI-отладка**: позиции/размеры — дамп `GetWorldCorners` живых ректов, не прикидка;
   перед тюнингом формы меряй фактические размеры (клетка/канвас-скейл) eval-ом.
6. **Мелкие шишки**: `powercfg` в Git Bash — дефис-форма (`-change`); `git add <каталог>`
   затягивает `.~lock.*#` LibreOffice — добавляй поимённо; `LogEntries` в 6000.6.8f1 —
   через `typeof(EditorWindow).Assembly.GetType` + `GetCount()`;
   `AssetDatabase.SaveAssetIfDirty` (не SaveAssetIfNeeded); CameraFollow уносит камеру
   между eval-вызовами — для скриншотов отключать на кадр.
7. **Лимит параллельных субагентов = 2**; волны по 2, файлы внутри волны не пересекаются.

## Чёрная дыра v4 (переработка владельца — главное состояние механики)

- **Не убивает**: пороги гибели (размер/приближение) и KillByCompression снесены.
- Захват (кольцо) запускает **медленное спагетти-сжатие 210с = 3.5 реальные минуты**
  (`BlackHoleShrinkSeconds` в PhysicsConfig_Default — теперь сериализован в ассете!),
  рейты 0.9-1.15 по глубине — окно ≈ стене.
- **Вырваться можно на малой глубине** (тяга против воронки Lerp(45..300, depth²);
  глубже — удержание намертво).
- **Единственный способ спастись — отключить корабль**: оверлей «ЧЁРНАЯ ДЫРА
  ЗАТЯГИВАЕТ» (кнопка + X, живой отсчёт «полное поглощение через N с») — привязан к
  захвату, гаснет при панелях.
- **Отключённый борт остаётся КРУЖИТЬ НА ОРБИТЕ** до конца своего окна
  (`WreckSystem.SpawnOrbital`: стабильный радиус, медленное сжатие, гаснет; MaxWrecks 3)
  — «виден с другого корабля». Полное поглощение = HullSystem.Abandon (списание,
  пересадка) без взрыва, без обломка.
- Захваченный корабль жив и управляем (движение в воронке), со временем теряет
  возможность вырваться; за старым порогом смерти (16с) — жив.
- Воронка v3 не тронута: Lerp(45..300, depth²), удержание 160→380, закрутка 45→130,
  SinkSpeedMax 12.
