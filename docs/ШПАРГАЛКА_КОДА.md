# Шпаргалка по коду SpaceTaxi (для защиты)

## 0. Как устроена папка Assets/Scripts

```
Scripts/
├─ UiKit/      примитивы uGUI — НИЧЕГО игрового (слой 1)
├─ UI/         все экраны игры (слои 2-3)
│   ├─ Common/     общие хелперы: UiFormat (Đ, 10k/1.4m, mm:ss), RollingNumber
│   │              (анимация докатки чисел), ToastNotifier (тосты)
│   ├─ Hud/        HUD: HudBinder (+Build), MinimapBinder, WaypointIndicator,
│   │              SpeedometerGauge, HudPalette
│   ├─ Map/        карта: MapScreenController (M), MapScreenBinder, PaperMap*
│   ├─ Menu/       главное меню: звёздное небо, кнопки, SceneFlowButtons
│   ├─ Onboard/    борткомп: Panel (TAB), Factory (каркас), Binder (данные)
│   ├─ Screens/    модалки: пауза, настройки, завершение заказа, увольнение
│   └─ Station/    станция (B): контроллер + StationUI + 2 секции
├─ Physics/    корабль: Ship, ShipController, HullSystem, LandingSystem,
│              GravityField, TrajectoryPredictor, эффекты
├─ Economy/    деньги: Wallet, DebtService, FleetService, FuelNetwork,
│              RepairNetwork, UpgradeConfig, PricingConfig, ShopStockService
├─ Orders/     заказы: OrderService, PassengerProfile/Generator, PassengerTask
├─ World/      мир: WorldBuilder, LevelAsset, Planet/Star/BlackHole/Comet...
├─ Core/       GameSession (центр всего), SaveSystem, DebugCheats
└─ Audio/      AudioManager, Sound/UiSfx (щелчок кнопок)
```

---

## 1. UI: три слоя (главный тезис защиты)

```
Слой 3: контроллеры/биндеры (MonoBehaviour) — строят экран при первом
        открытии, подписываются на события, перечитывают значения
Слой 2: игровые каркасы — OnboardComputerFactory (палитра, шрифт, секции,
        карточки), StationUI (кнопки, шапка, полоски, сегменты)
Слой 1: UiKit — Ui (Rect/Row/Column/Label/Button/Slider/WithAlpha...),
        UiBox (fluent: Box().Size().Background().Column()...), UiTheme (палитра)
```

Всё строится **кодом, не префабами**. Почему: геометрия детерминирована,
нет рассинхрона сцена↔код, проще рефакторить. Палитра одна (UiTheme),
цвета борткомпа (LabelColor и т.д.) — её роли под прежними именами.

## 2. Сквозные паттерны (одинаковы во всех экранах)

1. **Самоспавн контроллеров**: `[RuntimeInitializeOnLoadMethod]` + `sceneLoaded`
   → если `FindAnyObjectByType<T>() == null` → `new GameObject(...).AddComponent<T>()`.
   В сценах контроллеров НЕТ. (ModalBootstrap<T> — то же для модалок.)
2. **Ленивый бинд**: `Update → BindSession()` с флагом `bound` — ждёт GameSession
   и корабль, подписывается ОДИН раз за жизнь сессии.
3. **События вместо опроса**: `Wallet.CreditsChanged`, `ship.FuelChanged`,
   `hull.HpChanged`, `orders.OffersChanged`... В кадре — только анимации
   и SlowUpdate (раз в 0.25 с).
4. **Симметричная отписка** в `OnDestroy` — иначе события в разрушенный
   биндер = NRE.
5. **Каркас один раз**: `if (screen == null) screen = BuildScreen()`, дальше
   только `SetActive(true/false)` + Refresh.
6. **Анимации по unscaledTime** — живут при timeScale = 0 (пауза).

## 3. Клавиши и приоритеты экранов

| Клавиша | Экран | Пауза мира | sortingOrder |
|---|---|---|---|
| — | HUD | нет | сцена |
| Esc | Пауза | ДА | сцена |
| M | Карта (MapScreenController) | нет | сцена |
| TAB | Борткомп (OnboardComputerPanel) | нет | панель сцены |
| B | Станция (StationScreenController) | нет | 100 |
| — | Завершение заказа | ДА | 110 |
| — | Тосты | — | 120 |
| — | Увольнение | ДА | 200 |

**Арбитраж ESC**: каждый контроллер знает соседей через `IsOpened` и флаг
`EscJustClosed` (живёт один кадр, ставится при закрытии по ESC). Пауза
проверяет: карта/станция/завершение открыты ИЛИ только что закрылись по ESC
→ пауза не открывается тем же нажатием. Пары `Notify*Opened/*Closed`
прячут меню паузы под панелями. Tab при открытой карте закрывает карту
(панель борткомпа прячется вместе с ней) — статический `tabConsumedFrame`
гарантирует, что одно нажатие обработает один компонент.

## 4. Экран станции (B) — попап магазина/улучшений/заправки/ремонта

Файлы: `UI/Station/StationScreenController.cs` (каркас, вкладки, топливо,
ремонт), `StationUI.cs` (кнопка, шапка с кредитами и крестиком, Section
«// ЗАГОЛОВОК», FillBar/FillChild/SetFill, SegmentRow/SetSegments,
ServiceButton), `StationUpgradesSection.cs`, `StationShowcaseSection.cs`.

- **Открытие**: только `ship.State == Landed` на планете с услугами
  (`HasFuel || HasRepair`). Мир НЕ на паузу.
- **Вкладки** (enum StationTab): хаб МТО = все 4; обычная станция = по флагам
  планеты. Смена планеты → ApplyTabs пересобирает состав. На не-хабе блок
  улучшений живёт внутри окна ремонта.
- **Заправка**: 10 ячеек бака (SegmentRow, цвета как в HUD) + слайдер с
  `wholeNumbers` + живой предрасчёт суммы (`UpdateFuelOffer` на
  onValueChanged). По умолчанию слайдер на максимуме → кнопка
  «ЗАПРАВИТЬ ДО ПОЛНОГО». Подтверждение: `Wallet.TrySpend(cost)` →
  `ship.Fuel += units` → `landing.ReportServiced`. Экономика — в
  FuelNetwork/PricingConfig (тир сети, район, наценки).
- **Ремонт**: HP-бар (FillBar, ниже 25% — красный) + одна кнопка «Починить».
  Правило тиров: T1-мастерская берёт корабли 1–2, T2 — 1–3, T3+ — 4–5
  (`RepairNetwork.ShipTierAccepted`); чужой тир → «НЕ БЕРЁМСЯ».
- **Улучшения**: 4 линии (двигатель/бак/корпус/манёвр), у каждой «УР N → N+1»,
  прибавка из UpgradeConfig (макс/3), цена по классу корабля, полоска 3
  сегментов. Только свой корабль (аренда = сток). Долг ниже: виден при
  Balance > 0, «ПОГАСИТЬ ДОСРОЧНО» полной суммой.
- **Магазин (витрина)**: каталог ShipConfig из Resources, сортировка по цене.
  Слева 6 статов — полоска модели + янтарная риска твоего текущего +
  зелёный/красный отрезок разницы (все статы «больше = лучше»; масштаб —
  максимум по каталогу). Справа большой спрайт + свотчи покрасок (у аренды
  заблокированы). Кнопка контекстная: КУПИТЬ/ПЕРЕСЕСТЬ/СЕЙЧАС АКТИВЕН.
  Ротация покрасок раз в 2 игровых часа (ShopStockService.CurrentSlot),
  экран проверяет слот в Update и перерисовывается сам.
- **Секции — plain-классы** с интерфейсом `IStationSectionHost`
  (Session/Ship/CanOpen/ShowToast): контроллер дёргает Refresh, больше
  ничего про магазин не знает.

## 5. Бортовой компьютер (TAB)

Файлы: `OnboardComputerPanel.cs` (шторка), `OnboardComputerFactory.cs`
(каркас + карточки), `OnboardBinder.cs` + partials `.Cards/.Stats/.Radio`
(живые данные).

- **Panel**: слайд anchoredPosition.x, ease-out cubic, unscaled-время;
  страховка — если корутина умерла и позиция разошлась с флагом, Update
  выравнивает.
- **Factory.Build()** собирает сверху вниз: шапка (часы · деньги по центру
  панели якорем · ★рейтинг) → строка долга (скрыта при нуле) → активный
  заказ → скролл входящих → ЭФИР → ОТКЛЮЧИТЬ КОРАБЛЬ. Возвращает **OnboardRefs**
  — ссылки на узлы. **Контракт путей**: фабрика строит карточки с путями
  `Compact/Info/Name`, `Expanded/Summary/Wish`..., биндер находит их
  `transform.Find` и заполняет.
- **Binder.Cards**: `cardMap: OrderOffer → GameObject`. Входящие карточки
  раскрываются IN PLACE: Compact гасится, Expanded включается,
  `LayoutElement.preferredHeight` анимируется между константами фабрики,
  RectMask2D срезает контент. Протухшие — фейд и destroy. Активный заказ —
  всегда детальная карточка + красная «Отменить · −Đ N» + строка
  «ВЫПОЛНЕНИЕ: ✓ ЗАБРАТЬ → · ВЕЗИ» + таймер «ТОРОПИТСЯ» с цветом к красному.
- **Binder.Stats**: деньги/долг/рейтинг — RollingNumber (докатка значения);
  рейтинг при падении краснеет; кнопка «ПОГАСИТЬ · min(долг, кошелёк)».
- **Binder.Radio**: prev/next/мьют + «ВОЛНА 1/2/3» (плейлист → эмбиент →
  классика), названия станций.
- **SlowUpdate (0.25 с)**: часы, прогресс трека, живые расстояния карточек.

## 6. HUD и остальное UI

- **HudBinder**: скорость/прочность/10 сегментов топлива (узлы сцены) +
  код-достройка (спидометр со стрелкой, иконки, сирены). Подсказка цели
  сверху, баннер тревоги (приоритет: пустой бак > захват дыры > жар >
  зона дыры > мало топлива), HUD гаснет до 35% при открытых панелях
  (кроме тостов — своя CanvasGroup).
- **MinimapBinder** — радар (north-up, кламп к ободу), **WaypointIndicator** —
  стрелки-указатели цели у края экрана.
- **Карта (M)**: MapScreenController + MapScreenBinder (зум/панорамирование)
  + PaperMap* (стиль бумажной карты). Не пауза; открывает борткомп с собой.
- **Тосты**: ToastNotifier — на экране ОДИН, очередь с дедупом (тот же текст
  не чаще раза в 10 с), аварийные вперёд, тон Danger/Success/Neutral
  (красный = деньги ушли). Свой канвас (120).
- **Модалки**: ModalScreenControllerBase — открытие ставит timeScale = 0,
  закрытие любым путём возвращает; ESC/Enter с гвардом 0.25 с (нажатие кадра
  открытия не закрывает). Наследники: OrderCompleteScreenController
  (построчная разбивка выплаты с прокаткой чисел; ПРОБЕЛ не закрывает — это
  тяга), DismissalScreenController (увольнение, сейв удаляется, глушит
  паузу/карту/борткомп), SettingsBinder (через UiKit).
- **UiSfx.Hook(button)** — щелчок первым слушателем: слушатели onClick
  срабатывают по порядку добавления → звук раньше действия.

## 7. Не-UI (кратко)

- **GameSession** (Core) — центр: `.Ship .Wallet .Debt .Fleet .Orders
  .Rating .Payout .Config .Input`. Собирает мир, восстановление сейва,
  вызывает Show у OrderComplete после выплаты.
- **Ship** (Physics): `State (Landed/Flying)`, `LandedOn` (Planet), `Fuel`,
  `Hp`, `Eff` (эффективные статы с улучшениями), события FuelChanged.
  **ShipController** — ввод (WASD/Space, Input System). **HullSystem** —
  урон/респавн/Abandon (штатная потеря: «ОТКЛЮЧИТЬ КОРАБЛЬ»). 
  **LandingSystem** — посадка, ReportServiced. **GravityField** — все тела.
  **TrajectoryPredictor** — пунктир прогноза траектории.
- **Economy**: Wallet (TrySpend, CreditsChanged), DebtService (Balance,
  Repay, Dismissal при долге > порога, AccidentRegistered за аренду),
  FleetService (Current, IsOwned, TryBuy, TryUpgrade, SwitchTo), FuelNetwork
  /RepairNetwork (цены по тирам), UpgradeConfig, ShopStockService (ротация
  покрасок витрины).
- **Orders**: OrderService (Offers, Active, Accept/CancelActive, цена с
  бонусом рейтинга), PassengerProfile (портрет, фразы), PassengerTask
  (задания пассажира: дедлайн, без жара, мимо пояса, точки интереса).
- **World**: WorldBuilder строит уровень из LevelAsset (ScriptableObject):
  Planet (услуги: HasFuel/HasRepair/IsHub, тиры), Star (жар), BlackHole
  (захват/отключение), Comet, пояса астероидов.
- **SaveSystem**: Save/HasSave/MarkContinue/DeleteSave; автосейв при выходе.
- **AudioManager** живёт между сценами: волны музыки, громкости групп.

## 8. Вероятные вопросы препода — короткие ответы

- **Почему UI кодом, а не в редакторе?** Геометрия сложная и повторяющаяся:
  лейаут-группы + фиксированные высоты проще поддерживать кодом; префабы
  рассинхронизируются со скриптами. Сцены остаются для статичных узлов (HUD).
- **Как экраны узнают об изменениях?** События домена (CreditsChanged и
  т.д.), экраны не опрашивают модели. Подписка — один раз за сессию,
  отписка в OnDestroy.
- **Почему у текстов фиксированные высоты?** TMP Ellipsis режет и по
  вертикали: высота узла < высоты строки → текст «есть, но невидим».
  Правило: высота ≥ fontSize × 1.32.
- **Как работает ESC между экранами?** Флаг EscJustClosed на один кадр +
  взаимные проверки IsOpened: одно нажатие закрывает ровно один экран.
- **Что делает timeScale = 0 у модалок?** Мир ждёт; анимации при этом живут —
  они на unscaledTime.
- **Как покупка связана с UI?** UI только вызывает TryBuy/TryUpgrade/
  TrySpend; всю логику (деньги, владение, тиры) делают сервисы экономики,
  события после покупки перерисовывают экран сами.
