# Бриф Н3.3 — Большая карта: весь мир, хочется смотреть (slug: `bigmap-rework`)

## Контекст-блок
```text
(§2 из промпта-Н3)
Файл: Assets/Scripts/UI/MapScreenBinder.cs (карта по M; пан-драг + зум колесом
уже есть; процедурный «карандаш», бумага PaperMapArt, орбиты/сектора/буи).
Жалобы владельца: карта ОБРЕЗАЕТСЯ — видно не все планеты; непонятно что и где;
цель теряется; нарисовано «так себе» — не хочется туда смотреть.
```

## ЗАДАЧА
1. **Весь мир на экране**: при открытии карты автоподгон — bounding box всех тел
   уровня + поля (10%) вписывается в видимую область (зум-min по контенту).
   Ничего не обрезается по умолчанию; зум колесом уже есть — базовый масштаб =
   «весь мир», детализация колесом.
2. **Читаемость тел**:
   - планеты: круг с цветом сектора (бледные тёплые тона по PaperMapArt
     палитре: Near/Mid1/Mid2/Far — разные оттенки), подпись имени ВСЕГДА
     (мелкий кегль, не перекрывает соседей: вертикальный оффсет под круг);
   - у планет со станцией — значок (заправка/мастерская/хаб — Stamp-ячейки
     PaperMapArt или мини-глиф) рядом с именем;
   - звёзды — ореол + лучи (уже есть StarSketch), дыры — HoleSketch ✓ оставить;
   - цель заказа — крупный маркер (chevron TargetChevron + кольцо) и подпись
     «ЦЕЛЬ: <имя>» — должен находиться мгновенно;
   - маршрут активного заказа: пунктирная линия от корабля к пассажиру/цели
     (простая дуга по прямой — не траектория).
3. **Слои и рамка**: сетка секторов приглушить (не мешает), рамка карты-листа по
   границе мира; масштабная линейка (уже есть — проверить читаемость).
4. **Курсор**: hover по телу — имя крупнее + радиусы посадки/захвата тонкими
   кругами (уже есть частично — проверить).
5. НЕ трогать радар (Н3.2) и HUD.

## ЧТО НЕ ДЕЛАТЬ
- Не переделывать бумажную эстетику (PaperMapArt) — улучшать в её стилистике.
- Не трогать waypoint-механику (маркер «ПОМЕТИТЬ»).

## КРИТЕРИИ ГОТОВНОСТИ
- Открытие карты: весь мир виден сразу; каждая планета подписана; цель видна
  мгновенно; зум работает от «весь мир» до «одна планета».
- Компиляция 0 ошибок.

## Отчёт оркестратору
≤ 12 строк: что изменено, как решено «весь мир», что осталось.
