## ЗАДАЧА

Создать карту беты `Assets/ScriptableObjects/BetaMap01.asset` на базе
BigMap01 (24 планеты + 4 звезды уже в ассете) по ТЗ §4. AlphaMap01 остаётся
как есть.

1. Файл: скопировать Assets/ScriptableObjects/BigMap01.asset →
   BetaMap01.asset (git cp — новый файл + УНИКАЛЬНЫЙ новый guid в его .meta
   (создай .meta руками с новым guid — паттерн подтверждён; guid НЕ должен
   совпадать с BigMap01, иначе ассеты спутаются). LevelName в ассете —
   «БЕТА: система МТО» (или как в §4 называется).
2. Хаб: центральная планета «Гавань» (найти в YAML; если имя другое —
   СТОП и сообщи): StartPlanetIndex на неё, HasStation = true, Sector = Hub.
   Проверь, что спавн (SpawnAngleDeg/StartPlanetIndex) консистентен.
3. Сектора всем телам по дистанции от Гавани (центр-центр, пороги §4/П1.3):
   до ~800 Near, ~800–1400 Mid1, ~1400–2000 Mid2, дальше Far. Звёзды — по той
   же дистанции.
4. Станции: ровно 9 планет с HasStation = true по §4: хаб Гавань + 2 ближних
   + 3 средних-1 + 2 средних-2 + 0 дальний. Выбор внутри сектора — на твой
   вкус по валидации п.7 (достижимость), приоритет — крупные планеты
   (Radius больше) и равномерное покрытие сектора. Список выбранных — в отчёт.
5. Чёрная дыра: тело Type=BlackHole в точке (−2200, 4600) (§4 «соблазн
   срезать» через Средний-2), Radius ~55 (визуальный/горизонтальный размер;
   если рядом есть тела — минимальное расстояние до них ≥ 400).
6. Пояса: 2 обязательных (§4) — между парами «Толок→Сито» (Средний-1) и
   «Буй→Полынь» (Средний-2): тело Type=AsteroidBelt: Position — середина
   между планетами пары, Radius — половина дистанции между ними (осевая
   линия через обе), BeltWidth ~80, BeltAsteroidCount 30–36. Если пары с
   такими именами нет в BigMap01 — СТОП и сообщи фактические имена.
   Два пояса Дальнего сектора ДОБАВЛЯТЬ НЕ НАДО (§4 «по вкусу» — оставим
   владельцу на плейтесте).
7. Валидация (перепиши/расширь static Validate в Editor/LevelEditorWindow.cs
   под новые типы, если там жёсткие предположения о Planet/Star — проверь
   фактический код; в отчёте — результат прогонов по BetaMap01):
   - жаровые зоны звёзд (HeatRadius) не ближе 550 от спавна (§4);
   - пересечения тел (учитывая радиусы) — не должно быть;
   - достижимост станции: для каждой планеты без станции — дистанция до
     БЛИЖАЙШЕЙ станции её сектора ≤ запас хода корабля «своего» тира сектора
     (оценка: бак/расход 5.5 ед/с × скорость ~330 → дальность ≈ бак/5.5×0.6
     от центра до центра; пороги: Near ≤ ~1100, Mid1 ≤ ~1400, Mid2 ≤ ~1800,
     Far — без станций, проверка не нужна). Если планета не дотягивается —
     переставь станцию в п.4 (внутри сектора) и отчитайся.
   - WorldRadius: фактический размах тел (макс. |позиция|+радиус) + 1500
     запас (§4) — выставить в ассете.
8. Кометы — данные не нужны (CometSystem случайные хорды, П6.3; маршрут
   «южный квадрант» сделаем в П7.2/П9 — НЕ ДЕЛАТЬ здесь).
