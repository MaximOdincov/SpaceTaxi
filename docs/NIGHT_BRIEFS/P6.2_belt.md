## ЗАДАЧА

Пояс астероидов: полоса из N астероидов, вращающаяся вокруг центральной точки
(движение!), столкновение = урон, предупреждение при входе.

Числа [ПРЕДЛОЖЕНО, §3.8 — НЕ менять]: N = 24–40 (случайный при создании пояса),
r астероида 4–10 (случайный), урон (v − 55) × 0.9 с капом 30.

1. Данные: в `CelestialBodyData` (World/LevelAsset.cs) для Type == AsteroidBelt:
   - Position = центр пояса, Radius = радиус осевой линии кольца пояса.
   - Новые поля: `float BeltWidth = 40` (разброс астероидов вокруг осевой),
     `int BeltAsteroidCount = 30` (кламп 24–40 при создании).
     Editor LevelEditorWindow: поля видны/правятся, когда выбрано тело типа
     AsteroidBelt (кнопка «+ Пояс» рядом с «+ Звезда» — по образцу существующих;
     валидация пояса НЕ обязательна).
2. `Assets/Scripts/World/AsteroidBeltSystem.cs` — MonoBehaviour, создаётся
   WorldBuilder'ом для Type == AsteroidBelt (по образцу ветки BlackHole П6.1 —
   читай фактический код):
   - Init(CelestialBodyData, PhysicsConfig): спавнит BeltAsteroidCount
     дочерних астероидов: GO с CircleCollider2D (r 4–10, isTrigger=false) +
     SpriteRenderer StubSprites.Circle(2r, серо-коричневый тон — UseColor
     ветки BodyVisuals, если уместно; иначе константа цвета), позиция:
     угол случайный, радиус = Radius ± BeltWidth/2 (равномерно).
   - Вращение: вся система (родительский GO) крутится вокруг центра пояса
     с угловой скоростью `float BeltOrbitSpeed = 0.12` рад/с (поле класса,
     РЕШЕНИЕ координатора — не баланс §3.8, помечено как константа движения).
     Астероиды НЕ регистрируются в GravityField (мелкие, без гравитации).
3. `Assets/Scripts/World/Asteroid.cs` — маркер-компонент астероида (ns
   SpaceTaxi.World): Radius property, урон считает принимающая сторона.
4. Урон: LandingSystem.OnCollisionEnter2D — ветка «другое тело с Asteroid»:
   урон = min(30, (v − config.LandSpeed) × 0.9), при v < LandSpeed — без урона
   (скользящее касание); посадки на астероид НЕТ (ship отскакивает физикой,
   State не менять). AddShake пропорционально урону. ЭТОТ урон идёт в счёт
   столкновений заказа: файрить существующий `CrashImpact` (проверь фактический
   код П4.2 — событие уже существует, добавь вызов в новой ветке).
   Гибель от урона — обычный Died-путь (FailActive/респавн/долг — уже работают).
5. Предупреждение: AsteroidBeltSystem в Update следит за кораблём (ленивый
   поиск, стиль биндеров): вход в зону пояса (дистанция до центра пояса ≤
   Radius + BeltWidth/2 + 20) → ТОСТ ОДИН РАЗ при входе «Пояс астероидов:
   маневрируй аккуратно» (ToastNotifier.Show — ленивый FindAnyObjectByType
   в стиле проекта); при выходе из зоны+50 — флаг сбрасывается (повторный
   вход = новый тост).
6. Карта (MapScreenBinder): тела типа AsteroidBelt рисовать кольцом пояса
   (окружность Radius, тонкая, цвет приглушённый) — по образцу существующих
   веток тел; подпись DisplayName если в данных она есть. Миникарту НЕ трогать
   (пояс крупный, worldRange маленький).
