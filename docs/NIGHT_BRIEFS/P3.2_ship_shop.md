## ЗАДАЧА

Секция «Ангар» в экране станции (П3.1): каталог кораблей на продажу, покупка
и посадка в свой корабль (переключение между своими). Правила:
- Покупка только не-арендных (Price > 0) и не купленных; только стоя на станции
  (экран станции это гарантирует).
- Покупка списывает цену и СРАЗУ пересаживает (FleetService.TryBuy, П2.1 —
  полные HP/бак у нового корпуса).
- Переключение: сядь в любой свой корабль, пока стоишь на станции. Пересадка
  бесплатная, полные HP/бак (решение координатора: повреждения корпусов
  не персистятся в бете).
- Арендное «Яйцо» — не продаётся; показывается как «Аренда».

1. Каталог кораблей в рантайме: перенести ассеты `Assets/ScriptableObjects/Ships/*.asset`
   (вместе с их .meta) в `Assets/ScriptableObjects/Resources/Ships/`
   (создать папки; `git mv`, GUID не меняются — ссылки сцены останутся валидными;
   проверить после переноса `git status` и целостность). В коде каталог =
   `Resources.LoadAll<ShipConfig>("Ships")`, отсортировать по Tier, кэш один раз.
   Не создавать новых SO-каталогов и НЕ редактировать сцену.
2. `FleetService` дополнить: `void SwitchTo(ShipConfig config)` — только на
   owned (иначе no-op); Current = config, живой корабль Reconfigure с полными
   HP/баком; событие ShipChanged уходит. Проверки аренды: SwitchTo(аренда) —
   только если аренда не текущая? Аренда всегда «в наличии» — разрешить сядь
   в аренду (возврат на аренду без продажи своего) — да, разрешить.
3. Секция «Ангар» в StationScreenController (П3.1): список карточек кораблей:
   - Заголовок карточки: DisplayName + тир («Т3»).
   - Статы строкой: «Тяга 118 · Манёвр 100 · Бак 120 · HP 110 · Макс 410»
     (числа из ShipConfig, формат целых).
   - Статус: «В полёте (текущий)» / «В ангаре» / «Аренда» / цена «N кр».
   - Кнопки: «Купить N кр» (не куплен, Price>0; disabled если кредитов меньше),
     «Сесть в» (owned и не текущий). Разметка — стиль фабрики борткомпа/
     StubSprites, существующие константы цветов.
   - Обновление списка по ShipChanged/UpgradesChanged(нет)/CreditsChanged
     (доступность кнопок по деньгам) — подписки ленивые, без утечек.
   - Миниатюра корабля: слот под спрайт (пока StubSprites.ShipTriangle()
     с затенением по тиру — реальная графика придёт с артом А1/А2; не делать
     загрузку картинок).
4. Тосты: покупка — «Куплен "Стрела" (−2600 кр)» (emphasized); пересадка —
   «Пересел в "Скрепку"». ToastNotifier.Show из контроллера (UI знает о действии).
   Звук покупки — задача П9.3, здесь не добавлять.
