## ЗАДАЧА

1. **Новые SoundId** (Audio/SoundId.cs, стиль enum соседей — добавь В КОНЕЦ
   игровых, перед music-записями):
   `LowFuel` (сигнал, one-shot повторяющийся), `LowHull` (пульс), `BlackHoleHum`
   (луп, нарастающий), `BlackHoleSwallow` (one-shot «провал»), `BeltRumble`
   (луп стуков пояса).
2. **Мало топлива**: ShipAudio (у него есть input/ship доступ? смотри
   фактический код — он слушает ввод; для топлива подписка на ship.FuelChanged
   при Bind-паттерне): при FuelFraction ≤ 0.25 → PlayOneShot(LowFuel) раз
   (повтор: при пересечении порога 10% → второй сигнал; схема порогов как в
   HudBinder-баннере: 25% и 10%; НЕ чаще одного сигнала на порог за полёт,
   сброс при заправке выше порога).
3. **Мало HP**: при HpFraction ≤ 0.25 → LowHull one-shot (один раз до
   следующего ремонта выше порога; Repair/PaidRepair сбрасывает).
4. **Чёрная дыра**: BlackHole в зоне эффекта → Sound.StartLoop(BlackHoleHum)
   + SetLoopIntensity пропорционально близости к горизонту (1.0 у горизонта →
   0.3 у края зоны); выход из зоны → StopLoop. Достижение горизонта (гибель) →
   PlayOneShot(BlackHoleSwallow) + StopLoop. Код — в BlackHole.Update, где уже
   есть отслеживание корабля (фактический П6.1); идемпотентно (луп только один).
5. **Пояс**: AsteroidBeltSystem уже знает вход/выход (тост П6.2): вход →
   StartLoop(BeltRumble), выход → StopLoop (идемпотентно).
6. **Слоты для владельца** — документ: допиши в конец файла
   /Users/maxim/Desktop/SpaceTaxi/SpaceTaxiUnity/GameInfo/05_AUDIO.md раздел
   «Слоты беты (ночной прогон)» — таблица SoundId → ожидаемое имя файла →
   описание (LowFuel → sfx_low_fuel.ogg — короткий бип-сигнал; LowHull →
   sfx_low_hull.ogg — мягкий пульс; BlackHoleHum → sfx_blackhole_hum.ogg —
   нарастающий гул, loop; BlackHoleSwallow → sfx_blackhole_swallow.ogg —
   низкий «провал»; BeltRumble → sfx_belt_rumble.ogg — стуки/грохот, loop).
   Это ЕДИНСТВЕННОЕ исключение из запрета «не трогать GameInfo» — п.6 разрешён
   явно координатором.
