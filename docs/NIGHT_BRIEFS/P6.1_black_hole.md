## ЗАДАЧА

Чёрная дыра как тело системы (BodyType.BlackHole): гравитация ×8 сильнее
звезды, горизонт = гибель, в зоне захвата корабль МЕДЛЕННО уменьшается
(масштаб 1→0 за ~4 с) и исчезает.

Числа [ПРЕДЛОЖЕНО, §3.8 — НЕ менять]: масса ×8 (множитель к гравитации),
горизонт = r (радиус тела), зона эффекта = r × 6, уменьшение 1→0 за ~4 с.

1. `Assets/Scripts/World/BlackHole.cs` — класс : CelestialBody (ns
   SpaceTaxi.World), CreateAssetMenu НЕ нужен (тело строится WorldBuilder
   из данных уровня):
   - Init(data, config): читает Radius/MassMultiplier (масса ×8 — это
     MassMultiplier в данных, СМ. п.4; код берёт множитель как есть).
     Свойства: `float Horizon` (== Radius), `float EffectRadius` (Radius × 6).
   - Гравитация: GravityField.GetAccelerationAt использует GravParamOf
     (K × r × масса) — множитель массы уже в формуле; убедись, что BlackHole
     корректно регистрируется как тело (смотри, как CelestialBody.Init ставит
     Mass; у звёзд MassMultiplier 4.5 — для дыры данные уровня зададут 8;
     если MassMultiplier в данных дыры не хранит «×8» — по умолчанию
     WorldBuilder для BlackHole применяет множитель 8, если MassMultiplier < 8
     — РЕШЕНИЕ координатора: дыра всегда ×8, без сюрпризов конфига).
   - Update: корабль в зоне эффекта (EffectRadius) и НЕ в горизонтe →
     масштаб корабля плавно 1→0 за ~4 с (смотри фактический Ship: масштаб
     меняет transform.localScale корабля; коллайдер не трогать; при
     достижении ~0 — HullSystem.ApplyDamage(ship.Hp) = гибель). Выйд из
     зоны → масштаб восстанавливается к 1 плавно (быстрее, ~1 с).
     Отслеживание корабля — через GravityField? Проще: BlackHole.Update ищет
     корабль один раз лениво (смотри, как OrderService берёт ship; дыра —
     MonoBehaviour в мире, ленивый FindAnyObjectByType<Ship> в стиле биндеров
     допустим) и меряет дистанцию.
   - Горизонт (дистанция до центра ≤ Horizon): мгновенная гибель —
     ApplyDamage(ship.Hp) (смотри, как LandingSystem убивает звездой).
   - Визуал кодом: StubSprites.Circle(Radius×2) тёмный (ядро, UseColor из
     BodyVisuals поддерживается — см. WorldBuilder/CelestialBody) + ореол
     EffectRadius (как HeatZone у звезды: ребёнок «EffectZone», sortingOrder
     -1, полупрозрачный). БЕЗ частиц (эффект «провала» — П9.2 звук, визуал
     уменьшением уже есть).
2. WorldBuilder: ветка для data.Type == BlackHole — создать GO с BlackHole
   (по образцу звезды: без префаба, StubSprites, компонент; Planet-префаб НЕ
   использовать). Радиус из данных.
3. Death-flow: гибель в дыре = обычный Died → FAIL активного заказа,
   респавн, счётчики (FleetService/DebtService — уже подписаны; проверить,
