## ЗАДАЧА

Оплата за доставку. Сейчас событие OrderDelivered никому не платит (демо-кнопка
«СМЕНА +100 КР» — единственный источник кредитов). Формула (16 §3.5, числа
НЕ менять):

```
выплата = цена − штраф_столкновения − комиссия + чаевые (чаевые появятся в П8.2,
           сейчас всегда 0 — оставить точку расширения в API результата)
штраф: −15% от цены за каждое столкновение (урон корпуса от КОНТАКТА; жар
       звезды НЕ считается), кап −45%
комиссия аренды: −25% от (цена − штраф), только на арендном корабле
долг: с каждой выплаты 50% суммы автоматически уходит в счёт долга (пока долг > 0)
```

1. PricingConfig (П4.1) расширить полями: `PenaltyPerCollisionPct = 15`,
   `PenaltyCapPct = 45`, `RentalCommissionPct = 25`, `DebtRepaySharePct = 50`
   (ассет PricingConfig_Default.asset дополнить теми же значениями).
2. `Assets/Scripts/Economy/PayoutService.cs` — plain C# (владелец GameSession,
   свойство только для чтения `Payout`): метод
   `PayoutResult Pay(PricingConfig pricing, int price, bool rentalShip,
   int collisions)`; класс `PayoutResult` (в том же файле): `int Price,
   Penalty, Commission, Tips, ToDebt, Net`. Порядок:
   penalty = price × PenaltyPerCollisionPct × min(collisions, 3) / 100 (кап
   PenaltyCapPct; округление — AwayFromZero к целому); commission = rentalShip ?
   (price − penalty) × RentalCommissionPct / 100 : 0; gross = price − penalty −
   commission; ToDebt = debt.Balance > 0 ? min(gross × DebtRepaySharePct / 100
   (AwayFromZero), debt.Balance) : 0; Net = gross − ToDebt.
   Списание/начисление: `wallet.Add(Net)`, `debt.Repay(ToDebt)` — сервису
   передают Wallet и DebtService через Bind-метод (как у FleetService, без
   FindAnyObjectByType). Tips — поле результата (0) + параметр не добавлять,
   П8.2 подставит через отдельный метод/параметр по факту.
3. Счётчик столкновений: в LandingSystem добавить
   `event Action CrashImpact` — файрится ТОЛЬКО в ветке жёсткого касания с
   уроном (Crash, урон корпуса от контакта; звезда/жар — нет). OrderService
   подписывается в Init и считает столкновения АКТИВНОГО заказа (State == Active
   или Aboard, есть Active != null), сброс при Delivered/Failed/Cancelled/смене
   Active; публичное свойство `int CollisionsOfActive { get; }`.
4. Связка: GameSession подписан на Orders.OrderDelivered → собрать данные
   (цена: смотри фактический П4.1 — OrderOffer.Price; арендность —
   fleet.Current.IsRental; столкновения — orders.CollisionsOfActive; если
   событие OrderDelivered приходит уже после обнуления Active — обеспечь
   доступ к доставленному офферу минимальным способом, например свойство
   `OrderOffer LastDelivered` в OrderService, НЕ меняя сигнатуру события —
   на неё подписан ToastNotifier). Вызвать payout.Pay(...), вывести тосты:
   «Доставка: +N кр» (emphasized); если ToDebt > 0 — второй тост
   «M кр ушло в счёт долга». Тосты через ToastNotifier.Show из GameSession
   (или подписка ToastNotifier — как удобнее по стилю проекта).
5. Убрать демо-кнопку «СМЕНА +100 КР» из OnboardBinder (EnsureShiftButton,
   DemoShiftReward и связанный код) — экономика живая. Помеченный комментарий
   «временно, до П4» тоже убрать.
