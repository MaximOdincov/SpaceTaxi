# Бриф Н3.2 — Радар: север вверх, читаемые тела (slug: `radar-northup`)

## Контекст-блок
```text
(§2 из промпта-Н3)
Файл: Assets/Scripts/UI/MinimapBinder.cs (радар, корабль в центре,
RadarsWorldRadius=600 — константа). Сейчас: тела проецируются ОТНОСИТЕЛЬНО
корабля С ПОВОРОТОМ — при разворотах корабля мир описывает круги (владельца
это бесит). Спрайты тел — заглушки-точки, типы тел не различить.
Жалобы владельца: радар «двигается кругами»; тела не отличить (комета/планета);
область обзора тесновата.
```

## ЗАДАЧА
1. **Север вверх**: проекция тел = (body.position − ship.position), БЕЗ поворота
   на курс. Корабль — стрелка в центре, вращающаяся по носу (уже есть).
   «Вперёд» на радаре = мировая +Y (север). Маркер направления носа уже есть —
   оставить. Кламп тел к ободу — оставить (цель/waypoint/кометы).
2. **Тела — зелёные круги с типом**:
   - планета: зелёное кольцо (`StubSprites.Ring` или круг-контур), диаметр по
     классу размера (использовать фактический Radius / maxRadius мира);
   - звезда: кольцо крупнее, тёплый оттенок (охра) — отличима от планеты;
   - чёрная дыра: тёмное кольцо с точкой в центре;
   - комета: маленькая яркая точка + короткая линия-хвост по вектору скорости
     (у комет он известен из CometSystem — передать направление или хранить на
     Comet); комета ВНЕ клампа с ободом по дистанции — если далеко, просто
     стрелка-точка на краю (как цель);
   - цель заказа — мигающий маркер (уже есть), waypoint — янтарный (уже есть).
   Всё зелёная гамма по просьбе владельца (приглушённая, не кислотная).
3. **Область обзора**: RadarsWorldRadius 600 → 850 (константа наверху класса,
   переопределяемая). Кольца дистанций 200/400/600/800.
4. Производительность: кэш маркеров по телам (уже есть Dictionary — не плодить
   GO каждый кадр).

## ЧТО НЕ ДЕЛАТЬ
- Большую карту (M) не трогать (Н3.3). HUD не трогать. Компас/легенду радара
  можно поправить под новую ориентацию (надпись «С» сверху).

  различимы типами; комета видна и «едет».
- В логе: что изменено, как отличаются типы.
