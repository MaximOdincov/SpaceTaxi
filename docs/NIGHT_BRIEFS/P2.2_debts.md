## ЗАДАЧА

Долги за разбитые арендные корабли, счётчик аварий и экран увольнения
(проигрыш). Правила (16_BETA_PLAN §3.2, числа НЕ менять):
- Разбил/потерял арендный корабль → долг +400 кр (новый арендный выдаёт
  уже сделанный в П2.1 FleetService.NotifyShipLost).
- 3 аварии с непогашенными долгами → экран увольнения = проигрыш
  (сброс прогресса забега).
- Полностью выплатил долг → счётчик аварий обнуляется.
- АВТО-гашение 50% с каждой выплаты заказа и кнопка досрочного гашения
  на станции — ДРУГИЕ задачи (П4.2, П3.3); здесь только сервис с API.

1. `Assets/Scripts/Economy/DebtService.cs` — plain C# (не MonoBehaviour),
   владелец GameSession (создаётся в Awake рядом с Wallet/Fleet, публичное
   свойство только для чтения `Debt`). API:
   - `int Balance` — текущий долг (0 на старте), `event Action<int> DebtChanged`.
   - `void RegisterAccident()` — если текущий корабль был арендным (решение
     принимает вызывающий — GameSession, см. п.2): долг +400 (константа
     в сервисе с комментарием-источником 16 §3.1), счётчик
     `UnpaidAccidents` +1; если счётчик достиг 3 — событие `event Action Dismissal`.
   - `void Repay(int amount)` — уменьшает долг (клампит до 0), суммы > баланса
     не добавляют кредитов; при достижении 0 — `UnpaidAccidents = 0`.
     Кошельком сервис НЕ управляет (TrySpend делает вызывающий).
   - Свойства `int UnpaidAccidents { get; }`.
2. Связка с потерей корабля: в GameSession есть подписка на HullSystem.Died и
   HullSystem.ShipLost, где вызывается `fleet.NotifyShipLost()` (П2.1). Там же:
   если потерянный корабль был арендным (`!fleet.IsOwned(...)`, проверка ДО
   NotifyShipLost, который пересаживает на аренду) → `debt.RegisterAccident()`.
   Порядок и атомарность — на твой вкус, но двойного счёта быть не должно
   (Died и ShipLost при одном инциденте не должны сработать оба — смотри,
   как OrderService защищается; повтори тот же подход).
3. Тост о долге: при RegisterAccident (долге +400) — ToastNotifier.Show
   «ДОЛГ +400 кр за арендный корабль» (emphasized). Сервис не знает о UI —
   событие DebtChanged уже есть; тост вешает ToastNotifier или GameSession
   (как сделано для StationServiced — смотри автобинд ToastNotifier; если
   проще подписать в ToastNotifier — делай там).
4. Экран увольнения: новый UI-экран (полноэкранная панель) в стиле
   существующих экранов:
   - Создаётся кодом (стиль PauseScreenController / OnboardComputerFactory —
     каркас можно строить статической фабрикой в том же файле или соседнем
     Editor-совместимом; в рантайме создаётся при первом показе).
   - Показ по `DebtService.Dismissal`: `Time.timeScale = 0` (как пауза),
     панель поверх всего: заголовок «УВОЛЕН», текст-причина (2–3 строки,
     рус., тон фона: корпоративная сухость — «МТО расторгает договор.
     Долги не возвращены, аварий слишком много.»), кнопка «В МЕНЮ» →
     `SceneFlowButtons.LoadMainMenu()` (сброс забега = выход в меню;
     сейвов нет, инвалидацию сейва добавит П10.2).
   - После показа экран не должен повторно открываться при новых событиях.
   - Бинд: биндер-класс в UI (например DismissalScreenController) лениво ждёт
     GameSession.Debt (смотри ленивый паттерн OnboardBinder), подписка одна.
5. Долг на бортовом компьютере: в секции экономики (OnboardBinder, блок
   EconRow/EconCounters) рядом с кредитами — строка «Долг: N кр» (скрыта/
   пуста при долге 0; значение обновляется по DebtChanged + в SlowUpdate;
   стиль текста как у соседних строк, при долге > 0 — цвет DangerColor
   фабрики, если он доступен в контексте, иначе обычный).
