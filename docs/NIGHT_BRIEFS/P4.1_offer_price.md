## ЗАДАЧА

Фиксированная цена предложения на карточке заказа. Формула (16 §3.5, числа
НЕ менять):

```
цена = (база + дальность_эфф × 0.25) × класс_сектора_назначения
дальность_эфф = min(дальность, 1500)          — кап «через всю карту»
класс сектора планеты НАЗНАЧЕНИЯ: Hub 1.0, Near 1.0, Mid1 1.3, Mid2 1.6, Far 2.0
база = 40
```

Контрольные примеры (проверь свою реализацию на них):
- Ближний (Near), 500 юн: (40 + 125) × 1.0 = **165 кр**
- Средний-2 (Mid2), 1400 юн: (40 + 350) × 1.6 = **624 кр**
- Дальний (Far), 4000 юн (кап 1500): (40 + 375) × 2.0 = **830 кр**

1. `Assets/Scripts/Economy/PricingConfig.cs` — ScriptableObject
   (CreateAssetMenu "Space Taxi/Pricing Config"): `int BasePrice = 40`,
   `float PricePerDistanceUnit = 0.25`, `float DistanceCap = 1500`,
   `float SectorHubMul = 1.0`, `SectorNearMul = 1.0`, `SectorMid1Mul = 1.3`,
   `SectorMid2Mul = 1.6`, `SectorFarMul = 2.0` + метод
   `float GetSectorMultiplier(Sector)` (switch по enum; ns SpaceTaxi.Economy,
   using SpaceTaxi.World для Sector).
   Ассет `Assets/ScriptableObjects/PricingConfig_Default.asset` — создать
   YAML-файлом (паттерн Ships/*.asset) с этими значениями.
   ЗАМЕТКА: удали `Assets/Scripts/Economy/SectorPricing.cs` (+ его .meta) —
   его коэффициенты переезжают в PricingConfig (ревью-заметка П1: множители
   должны жить в SO). Вызовов у него нет.
2. `Assets/Scripts/Economy/OrderPricing.cs` — static-класс:
   `static int ComputePrice(PricingConfig, float routeDistance, Sector
   dropoffSector)` → int (округление по правилу: цена должна совпадать с
   контрольными примерами — считай в float, итог Math.Round к целому,
   от дефолтного MidpointRounding.ToEven НЕ полагайся — используй
   MidpointRounding.AwayFromZero, чтобы 623.5 → 624).
3. OrderService: поле `[SerializeField] PricingConfig pricingConfig` (в сцене
   не назначен — фолбэк-инстанс с дефолтными значениями, паттерн
   ShipConfig.EggRentalFallback; никаких NRE). В `AddOffer` вычислять цену и
   хранить в OrderOffer: новое поле `int Price` (публичное readonly-свойство
   или поле — как остальной OrderOffer). Дальность — существующий
   `RouteDistance(offer)` (посчитай ДО сохранения, в момент спавна).
   Точка расширения: параметр-множитель на будущее (рейтинг ≥4.0 → ×1.1,
   П4.3) — сейчас просто не применяется; оставь сигнатуру ComputePrice без
   рейтингового параметра (П4.3 добавит обёртку), не придумывай лишнего.
4. UI карточки: в OnboardBinder у карточки оффера строка оплаты
   (узел `Info/Route` сосед — смотри BuildOfferCard: есть ли узел оплаты;
   если нет — добавь строку «Цена: N кр» в Info карточки, стиль соседних
   строк; текст ярче, цена — акцентный цвет TaxiColor, если он доступен).
   В активном заказе (BuildActiveOrderBlock) цена видна в блоке статуса
   («Цена: N кр») — обновляется при Aboard (значение берётся из
   orders.Active.Price).
