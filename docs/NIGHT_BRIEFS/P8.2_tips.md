## ЗАДАЧА

Чаевые: выполненное задание пассажира → чаевые сверх цены.

1. **Щедрость архетипа** — в PassengerPools.ArchetypePool (П5.1) добавить поле
   `float TipsPct` (доля от цены): Торопыга 0.15, Барыга 0.10, Турист 0.20,
   Тихоня 0.10, Чудик 0.25 (ассет PassengerPools.asset дополнить теми же
   значениями у каждого архетипа). Если профиль создаётся генератором —
   PassengerProfile должен нести архетип (он несёт строку Archetype — смотри
   фактический П5.2) —Lookup щедрости по архетипу в момент выплаты.
2. **Хук в выплату**: PayoutService.Pay — добавить параметр `float tipsFraction`
   (0 = нет чаевых; П4.2 вызов передаёт 0): Tips = round(price × tipsFraction
   × meridianBonus, AwayFromZero), где meridianBonus = 1.1 если текущий
   корабль — «Меридиан» (FleetService.Current.Id == "meridian" — константу
   id перка пометить комментарием-источником 16 §3.3; множитель
   `MeridianTipsBonusMul = 1.1` — поле PricingConfig, ассет дополнить).
   PayoutResult.Tips уже учитывается в Net (П4.2: проверь фактическую формулу
   — если Tips ещё не вычитается/прибавляется в Net — добавь: Net = price −
   penalty − commission + Tips − ToDebt).
3. **Связка**: GameSession (или фактический подписчик OrderDelivered) при
   выплате вычисляет долю: задание пассажира Succeeded (PassengerTask, П5.3/П8.1)
   → TipsPct архетипа; иначе 0. Долю берёт из PassengerPools (через каталог —
   смотри фактический доступ к пулам П5.2; если пулы не доходят до GameSession —
   минимальный геттер).
4. **UI**: экран завершения (П4.3) уже скрывает ноль и показывает «Чаевые +T кр»
   — просто убедись по фактическому коду, что Tips теперь ненулевые попадают
   в PayoutResult.LastResult. Дополнительно: если задание выполнено, на экране
   завершения показать строку «Задание пассажира: выполнено» (мелким, стиль
   соседних) — берётся из task state; данные в LastResult не пихать — экран
   может читать orders/task напрямую (UI-слой).
5. Пример проверки (§3.5): цена 624, Турист (20%) → чаевые 125 → выплата
   растёт на 125 (проверь свою арифметику на этом примере, округление
   AwayFromZero).
