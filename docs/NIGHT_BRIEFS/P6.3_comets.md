## ЗАДАЧА

Кометы: 3 маршрута по таймеру, циклично; летят быстро, видны издалека,
предупреждение на миникарте за 20 с до появления; столкновение = гибель
(как звезда).

Числа [ПРЕДЛОЖЕНО, §3.8 — НЕ менять]: скорость ~400, интервалы 90–150 с
(случайный), предупреждение за 20 с.

1. `Assets/Scripts/World/CometSystem.cs` — MonoBehaviour, создаётся
   WorldBuilder'ом ОДИН раз на уровень (после тел; смотри фактический порядок
   сборки мира П6.1/П6.2):
   - Поля-настройки (константы §3.8): `int MaxRoutes = 3`, `float CometSpeed = 400`,
     `float SpawnIntervalMin = 90`, `SpawnIntervalMax = 150`,
     `float WarningSeconds = 20`, `float CometRadius = 6`.
   - Событие `event Action<Vector2, Vector2> CometIncoming` (позиция входа,
     направление) — за WarningSeconds до появления.
   - Цикл: таймер (пауза-безопасный — смотри фактический подход таймеров
     OrderService; unscaled НЕ нужен, время мира) → за 20 с до спавна событие
     CometIncoming → спавн кометы → следующий таймер = случайный интервал.
   - Маршрут: случайная хорда через мир (смотри LevelAsset.WorldRadius):
     точка входа на окружности мира, направление внутрь под случайным углом
     (НЕ через стартовую планету — смести точку входа от SpawnPoint на ≥ 500,
     чтобы первая комета не убивала новичка).
   - Комета: дочерний GO — CircleCollider2D (CometRadius, isTrigger=false),
     SpriteRenderer StubSprites.Circle (яркий голубовато-белый, константа),
     TrailRenderer по образцу SpeedTrail (цвет как у кометы, тайлится тем же
     материалом) — след виден издалека. Комета НЕ в GravityField.
2. `Assets/Scripts/World/Comet.cs` — маркер-компонент (ns SpaceTaxi.World):
   линейное движение в Update (transform.position += dir × CometSpeed × dt),
   смерть за границей мира + 200 (Destroy GO).
3. Столкновение: LandingSystem.OnCollisionEnter2D — ветка «другое тело с Comet»:
   мгновенная гибель (ApplyDamage(ship.Hp), как звезда — смотри фактическую
   ветку Star). ЭТО НЕ CrashImpact (не штраф столкновения — это гибель,
   провал заказа уже ловит Died-путь).
4. Предупреждения UI:
   - ToastNotifier: подписка на CometSystem.CometIncoming → тост
     «Комета приближается!» (emphasized). CometSystem не знает о UI.
   - MinimapBinder: подписка на CometIncoming — стрелка/маркер направления
     на 20 с (цвет тревоги, стиль существующей PlayerArrow; маркер за границей
     радара — кламп к краю радара), исчезает при спавне кометы
     (добавь событие CometSpawned или закрывай по таймеру 20 с — на твой вкус,
     без утечек).
5. AlphaMap01/BigMap01 НЕ трогать (маршруты зададутся на BetaMap в П7.1 —
   сейчас случайные хорды достаточны для механики).
