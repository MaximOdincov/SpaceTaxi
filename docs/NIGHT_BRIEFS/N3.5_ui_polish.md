# Бриф Н3.5 — Полировка UI + чистка кода (slug: `ui-polish`, ПО ОСТАТКУ НОЧИ)

## Контекст-блок
```text
(§2 из промпта-Н3)
Это последняя задача реестра и единственная «по вкусу»: делать только если
Н3.0-Н3.4 закрыты и есть время/токены. Мелкими независимыми шагами, каждый —
отдельный коммит, компиляция после каждого. Если что-то не влезло — в лог
«НЕ УСПЕЛО» (не тащить полуделанное).
```

## ЗАДАЧА (буфер идей — выполнять по убыванию ценности, реши сам)
1. **Плавность UI**: анимации открытия станции/борткомпа/карты — единый тайминг
   (0.18-0.25с, easeOut); тосты — лёгкий выезд+фейд уже есть, проверить
   согласованность; переходы панели заказа (раскрытие) — уже есть.
2. **HUD**: значения скорости/бака/HP — единая типографика; GoalHint не
   конфликтует с баннером тревоги (расположение).
3. **Борткомп**: выровнять секции (паддинги, отступы заголовков «//»), Clock —
   живая минута по игровому времени уже есть, проверить кегли после Н-правок.
4. **Карточка раскрытого заказа**: проверить перенос длинных заданий (Task
   TextArea — рост высоты), не ломать Layout.
5. **Чистка кода** (осторожно, малыми коммитами):
   - убрать мёртвые PlayerPlay-глифы (▶/||) из фабрики/биндера, если остались;
   - `OnboardRefs.MoneyIcon` больше не используется фабрикой — проверить и
     удалить поле + обращения (null-guarded, безопасно);
   - легаси `ShipConfig.Retro=0`-фолбэки — проверить единообразие;
   - `StubSprites` неиспользуемые хелперы — НЕ удалять (используются картой).
6. **Найти и починить** любые NRE в логе прошлых прогонов (если оркестратор
   видел в Console-логах батчей — их там нет, пропустить).

## ЧТО НЕ ДЕЛАТЬ
- Не переписывать большие системы (радар/карта/витрина — Н3.2-Н3.4).
- Не трогать баланс (Н3.1). Не ломать сейв.
- Каждый шаг — компиляция; полуделанное не коммитить.

## КРИТЕРИИ ГОТОВНОСТИ
- Серия мелких коммитов, каждый компилируется; лог: что вошло, что в «НЕ УСПЕЛО».

## Отчёт оркестратору
≤ 12 строк: список вошедших полировок, «НЕ УСПЕЛО» списком.
