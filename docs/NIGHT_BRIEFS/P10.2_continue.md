## ЗАДАЧА

1. Кнопка «Продолжить» (Button_Continue, MainMenu):
   - При показе меню (Awake/OnEnable сцены, а также при КАЖДОМ возврате в меню —
     смотри фактический код SceneFlowButtons/загрузку сцены): интерактивна,
     если `SaveSystem.HasSave()`; иначе `interactable = false` + затемнение
     (alpha 0.4, стиль существующих кнопок; канвас-группу не ломать — смотри,
     как кнопки оформлены).
   - `ContinueGame()` (существующий метод): перед загрузкой GameScene —
     `SaveSystem.SetContinueFlag()` (или фактическое имя API П10.1; смотри,
     как П10.1 реализовал флаг). Если сейва нет — кнопка уже неактивна
     (страховка: и в методе no-op).
   - `StartNewGame()` — флаг продолжения НЕ ставит (обычный запуск; сейв
     не удаляется — перезапишется автосейвом).
2. Инвалидация при увольнении: П10.1 уже удаляет сейв на экране увольнения —
   убедись (по фактическому коду) и при необходимости доделай: после удаления
   кнопка «Продолжить» в меню неактивна при следующем показе (п.1 покрывает,
   если проверка идёт при каждом показе).
3. Кривой сейв: HasSave возвращает true (файл есть), но TryLoad упадёт в
   GameScene → П10.1 молча откатывает к новой игре. Тогда кнопка была кликабельна
   зря — ДОПУСТИМО (ошибок нет, игра работает); НЕ усложняй.

## ЧТО НЕ ДЕЛАТЬ

- Не делать удаление сейва по «Новая игра», не трогать настройки/громкости,
  сам SaveSystem (только API-вызовы), баланс-числа, .unity сцены руками.

## КРИТЕРИЙ ГОТОВНОСТИ

- Кнопка «Продолжить» активна только при наличии сейва, при увольнении —
  неактивна при следующем показе меню; «Продолжить» грузит сейв, «Новая игра» — нет.
- Ветка agent/beta-continue, 1–2 коммита (сообщения на русском).
