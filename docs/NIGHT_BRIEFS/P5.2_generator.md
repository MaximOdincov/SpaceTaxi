## ЗАДАЧА

Генератор пассажиров: каждый новый заказ — свежий профиль, собранный из пулов
П5.1 (имя+фамилия, архетип, реплики). Существующий единственный
Passenger_Default остаётся фолбэком.

1. Переписать `Assets/Scripts/Orders/PassengerGenerator.cs` (легаси мёртвое —
   замени содержимое целиком; класс public static, ns SpaceTaxi.Orders):
   `static PassengerProfile Create(PassengerPools pools)`:
   - `ScriptableObject.CreateInstance<PassengerProfile>()` (runtime-инстанс,
     НЕ ассет; Destroy не нужен — живёт со сцены, как остальные данные сессии).
   - FullName = «Имя Фамилия» (случайные из pools.PickName/PickSurname).
   - Archetype = случайный ArchetypePool из pools → его `Archetype`.
   - Greetings/Thanks/Complaints = ПОЛНЫЕ копии массивов пула архетипа
     (реплика выбирается случайно при показе — PickPhrase в PassengerProfile).
   - Wishes = копия Wishes пула (тексты заданий; конкретное задание+текст
     подставит П5.3/П8.1 — здесь пул как заглушка-разнообразие).
   - Description = пусто (UI не ломается), Portrait = null (UI покажет
     цветную заглушку), `PortraitTint` = случайный из фиксированной палитры
     8 цветов (константы в генераторе, спокойные тёплые/холодные тона —
     визуальное разнообразие до арта А5).
   - pools null → вернуть null (фолбэк на стороне каталога).
2. PassengerCatalog: подключить пулы:
   - поле `[SerializeField] PassengerPools pools` + ленивый фолбэк
     `Resources.Load<PassengerPools>("PassengerPools")` (ассет П5.1 лежит в
     Resources; кэш после первой загрузки).
   - новый метод `PassengerProfile Generate()` — PassengerGenerator.Create(pools);
     если pools нет → null.
   - `Pick()` остаётся как есть (старый путь).
3. OrderService.AddOffer: брать пассажира так:
   `var p = catalog.Generate(); if (p == null) p = catalog.Pick();`
   (остальная логика оффера не меняется; если Pick тоже null — смотри
   фактический код: там уже есть обработка пустого каталога — сохранить).
