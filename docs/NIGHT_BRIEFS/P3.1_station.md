## ЗАДАЧА

Экран станции. Сейчас посадка на планету со станцией БЕСПЛАТНО чинит и
заправляет (LandingSystem: HasStation → RepairAll + Fuel=FuelMax). По бете
сервис платный: **1 кр = 1 ед топлива, 1 кр = 1 HP** (16 §3.1). Экран —
каркас, на который лягут магазин кораблей (П3.2) и улучшения/долг (П3.3):
сейчас — только структура + заправка/ремонт.

1. Убрать бесплатный сервис: в LandingSystem вместо RepairAll+полного бака при
   посадке — ничего платно/бесплатно не начислять; вместо этого после мягкой
   посадки на планету со станцией — тост-подсказка через существующий тост-поток
   («Станция: [B] — сервис, магазин»). Событие `StationServiced` сохранить и
   fireEvent'ить из нового платного пути (см. п.4) — ToastNotifier уже подписан
   на него и скажет «заправлено/отремонтировано». Если событие логичнее перевести
   на новый сервис-класс — можно, но минимизируй рефакторинг и сохрани подписку
   тостов рабочей.
2. Ввод: новое действие `Station` в мапе "UI" (или отдельной мапе — по образцу
   существующих) в `Assets/Settings/GameInput.inputactions` (YAML, стиль соседей;
   binding B). Читается runtime-строками, как делают ShipController/MapScreenController
   — смотри их SetInput/паттерн подписки.
3. `Assets/Scripts/UI/StationScreenController.cs` + биндер (один файл или два —
   как удобнее, стиль соседей): экран доступен ТОЛЬКО когда корабль стоит
   (State == Landed) на планете с HasStation. Открытие по B, закрытие по B/Esc
   (Esc занят паузой — смотри, как MapScreenController договаривается с паузой
   через NotifyMapOpened/Closed; повтори договорённость: при открытом экране
   станции ESC не открывает паузу, а закрывает станцию). Пауза мира не нужна:
   корабль стоит, время идёт (как карта — смотри, ставит ли она timeScale; карта
   не ставит — станция тоже НЕ ставит). Ленивый бинд по паттерну биндеров.
4. Заправка/ремонт (секция «Сервис»):
   - Показ: имя станции (планеты), полоса/числа топлива (Fuel/FuelMax) и HP
     (Hp/HpMax) — как в HUD, стилем фабрики борткомпа.
   - Кнопка «Заправить до полного (N кр)»: N = ceil(FuelMax − Fuel) (1 кр = 1 ед);
     если кредитов меньше — заправить сколько хватает (partial), вывести
     фактически потраченное; 0 при пустом кошельке — кнопка disabled-вид.
   - Кнопка «Ремонт до полного (N кр)»: аналогично (1 кр = 1 HP).
   - Списание через Wallet.TrySpend, примен — ship.Fuel/Hull RepairAll-путь
     (смотри фактический код Ship/HullSystem; события FuelChanged/HpChanged
     должны дойти до HUD).
   - После любой оплаченной услуги — StationServiced (тост).
5. Структура экрана под будущие секции: панель с заголовком «СТАНЦИЯ …» и
   контейнером секций (Сервис / Магазин — пустой слот с подпиской «П3.2»
   НЕ оставлять, просто закладка в layout — коллапсируемый контейнер), визуал —
   StubSprites/фабричные цвета (LabelColor/BrightColor/TaxiColor/PanelColor
   из OnboardComputerFactory, если публично доступны; иначе локальные константы
   в том же стиле). Экран строится кодом при первом открытии (паттерн
   ToastNotifier/кастомных экранов), НИКАКИХ правок .unity-сцены руками.
