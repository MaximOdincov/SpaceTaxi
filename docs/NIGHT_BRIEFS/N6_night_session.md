## ПРОМПТ ОРКЕСТРАТОРУ (вставить первой командой в новую сессию)

Ты — оркестратор ночной сессии SpaceTaxi. Владелец спит. Прочитай целиком, в этом порядке:
1. `docs/NIGHT_BRIEFS/N6_night_session.md` (этот бриф).
2. `docs/NIGHT_LOG5.md` — что сделано в Н5 (группы A/B/C/D/G, карта «один слой», станция, баланс).
3. `AGENTS.md` — конвенции и шишки (TMP 1.32, плей-режим останавливает агент, внешние правки сцены →
   перезагружай сцену, TMP-ассет через eval — с AddObjectToAsset).

Правила:
1. Субагенты: unity-scripter (C#/ассеты), unity-ui-builder (UI), unity-analyst (разведка).
   Оркестратор принимает дифф, проверяет компиляцию/замеры, коммитит.
2. **ДИСЦИПЛИНА РЕДАКТОРА (инцидент Н5-день: один субагент ушёл, оставив занятый редактор/сцену,
   второй ждал его 1.5 часа — владелец прервал вручную):**
   - субагент после КАЖДОЙ проверки: `editor.playmode stop`; перед финальным отчётом — убедись
     `playing=false`;
   - субагент НЕ ЖДЁТ занятый редактор: таймаут/EDITOR_BUSY → пауза 60-90 с, максимум 3 попытки,
     дальше работа офлайн (код/дифф), компиляция позже — и пометка в отчёте;
   - оркестратор перед запуском каждого редактор-агента: `unity status --until-ready` + плей
     остановлен; агентов с доступом к редактору запускать так, чтобы они не бились за него
     одновременно (см. «Порядок»: в волне редактор-задачи чередуются, у каждого свои файлы);
   - если прошлый агент оставил плей — оркестратор первым делом `editor.playmode stop`.
3. **Скорость**: не зацикливайся на проверках. Приёмка по умолчанию — compile 0/0. Замеры eval —
   только где дёшево (одна команда). Скриншот — максимум 1-2 на карту/меню. Застрял > 20 мин —
   PARTIAL, коммит, следующая задача.
4. Сейв пользователя не трогать. Сцены руками (YAML) не править — только eval/SerializedObject.
   Внешне изменённый .unity → перезагрузить сцену (OpenScene) перед проверками.
5. Ветка `feature/beta`, коммиты `Н6.<номер>: <что> — compile EXIT 0`, не пушить, git-историю не
   переписывать. Ночной лог: `docs/NIGHT_LOG6.md` — создаётся в чекпоинте, обновляется после
   каждой задачи (статус/файлы/решения/как проверялось/вопросы/коммит).
6. Ориентир — 6 часов на ВСЕ задачи. Если горит: режь полировку, не режь охват; честный PARTIAL
   лучше «сделал на глаз».
