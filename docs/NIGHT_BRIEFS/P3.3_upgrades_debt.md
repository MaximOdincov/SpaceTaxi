## ЗАДАЧА

Заполнить коллапсируемую секцию «ShopSection» экрана станции (П3.1) двумя
блоками: покупка улучшений 4×3 и досрочное гашение долга.

1. **Блок «Улучшения»** (для ТЕКУЩЕГО корабля, `fleet.Current`):
   - Если арендный (IsRental / !IsOwned): одна строка «Аренда всегда сток —
     улучшения только на свой корабль» (без кнопок).
   - Если свой: 4 строки по линиям UpgradeLine (Engine/Tank/Hull/Maneuver,
     имена из UpgradeConfig — «Двигатель/Бак/Корпус/Манёвровые»):
     - Текст строки: имя линии + текущий уровень «ур. N/3» + краткий эффект
       следующего уровня (готовые строки-описания зашиты константами рядом с
       UI, например «+8% тяги» для ур.1 → считай из UpgradeConfig: maxEffect/3;
       НЕ дублируй числа — бери из конфига и дели).
     - Кнопка «Купить (N кр)»: N = PricesPerLevel[текущий уровень]; вызов
       `fleet.TryUpgrade(fleet.Current, line, wallet)`; disabled при ур.3,
       нехватке денег; при успехе строка обновляется (эффект применится сам —
       Ship.Eff пересчитывается в TryUpgrade, без лечения/заправки).
   - Обновление блока: подписки FleetService.UpgradesChanged + Wallet.CreditsChanged
     + FleetService.ShipChanged (сменил корабль — блок перестроился), лениво,
     без утечек (сессия одна на сцену).
2. **Блок «Долг»** (показывается только при debt.Balance > 0):
   - Строка: «Долг: N кр · Аварий: K/3» (DangerColor-стиль П2.2).
   - Кнопка «Погасить досрочно (N кр)»: гашение ПОЛНОЙ суммы сразу (§3.2);
     доступна только если wallet.Credits >= Balance: `wallet.TrySpend(Balance)`
     → `debt.Repay(Balance)`; при нехватке денег кнопка disabled.
   - При полном погашении — тост «Долг погашен» (emphasized) — из контроллера
     (UI знает о действии); счётчик аварий обнулится сам (DebtService.Repay).
   - Обновление по DebtChanged.
3. Стиль — как секция СЕРВИС (фабрика борткомпа, цвета/шрифт те же);
   НИКАКИХ правок .unity/.prefab руками.
