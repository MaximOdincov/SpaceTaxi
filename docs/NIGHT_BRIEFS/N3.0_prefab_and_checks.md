## ЗАДАЧА
Ночь стартует с текущего состояния `feature/beta` — оно уже компилируется
(проверено днём, 0 ошибок), но нужно зафиксировать базу и прогнать проверки.

1. Полная компиляция Unity batchmode (команда из промпта-Н3). Ошибок быть не
   должно; если есть — чинить в рамках ветки Н3.0.
2. Пересборка префаба борткомпа под актуальную фабрику:
   `-executeMethod SpaceTaxi.Tools.OnboardComputerBuilder.RebuildPrefab`
   (headless, днём не успели). После пересборки — снова компиляция.
3. Прогнать селфчеки и занести вывод в лог:
   - `-executeMethod SpaceTaxi.EditorTools.ArtSelfCheck.RunFromCLI` — 0 провалов
     (пулы арта, ShipConfig-спрайты, префабы моделей, NPC, коллажи).
   - `-executeMethod SpaceTaxi.EditorTools.ShipProbe.Run` — offset всех моделей
     ≤ 1 юнита (печатается в лог).
4. Проверить, что в HUD-сцене есть узлы `SpeedIcon`, `HullIcon`, `SpeedValue`
   (HudBinder ожидает их по именам) — если какого-то нет, Занести В ЛОГ как
   «ВОПРОСЫ УТРА» (не чинить вслепую).
5. Коммит `agent/n3-night3-hygiene` → merge → лог.
