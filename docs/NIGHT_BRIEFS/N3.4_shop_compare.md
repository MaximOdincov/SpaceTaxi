## ЗАДАЧА
1. **Карточка витрины крупнее**: окно магазина шире (проверить ScrollRect/панель
   — если тесно, увеличить долю секции), спрайт корабля крупнее (168×122 →
   ~220×160), статы — не строкой, а **таблицей-списком** из 6 строк:
   Тяга, Манёвр, Макс. скорость, Бак, Прочность, Торможение.
   Для каждой — **полоска сравнения с ТЕКУЩИМ кораблём**:
   - серая полоса = значение текущего корабля (база сравнения);
   - цветная полоса = показываемой модели (зелёная — лучше, красная — хуже);
   - справа процент: «+18%» / «−7%» (к текущему, 0% если равен);
   - текущий корабль в листании подсвечивается («ВЫ ЗДЕСЬ» бейдж).
   Полосы: RectTransform с fill-дочкой (Image), ширина = value/maxAmongAll.
   Все 6 статов из ShipConfig (Retro и VisualLength включить; ретро показывать
   «тормозной путь» = обратная величина — юзеру понятнее, подписать ед.)
2. **Секция УЛУЧШЕНИЯ**: у каждой линии — предпросмотр: «Тяга 140 → 161 (+15%)»
   (старое/новое значение + полоска-прирост) и «окупится за ~N заказов» (цена
   линии / прирост дохода — приблизительно, формулой из ShipConfig/UpgradeConfig;
   если посчитать нельзя — просто прирост%). Числа брать из ShipStats.Compute
   с текущим и следующим уровнем.
3. **Порядок и стиль**: стиль фабрики (LabelColor/BrightColor/TaxiColor),
   рамки кнопок уже есть (Outline). Не ломать кнопки КУПИТЬ/СЕСТЬ В и тосты.
4. Обновление по ShipChanged/CreditsChanged — уже есть, сохранить.
