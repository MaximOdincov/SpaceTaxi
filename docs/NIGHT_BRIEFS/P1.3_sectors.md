## ЗАДАЧА

У тел системы появляется поле «сектор» — оно задаёт класс района для будущей
формулы оплаты заказов (цена зависит от сектора планеты НАЗНАЧЕНИЯ). Формулу
оплаты делать НЕ надо (это П4), только данные.

1. В `Assets/Scripts/World/LevelAsset.cs` у `CelestialBodyData` добавить поле
   `Sector`, enum: `Hub, Near, Mid1, Mid2, Far` (по умолчанию `Near`).
   enum можно объявить внутри CelestialBodyData или рядом в файле (ns SpaceTaxi.World).
2. Новый статик-класс `SectorPricing` — файл `Assets/Scripts/Economy/SectorPricing.cs`
   (ns SpaceTaxi.Economy): `public static float GetPriceMultiplier(Sector)` →
   Hub 1.0, Near 1.0, Mid1 1.3, Mid2 1.6, Far 2.0. Использоваться будет в П4 —
   сейчас только данные (вызова ещё нет — так и должно быть).
3. Редактор уровня `Assets/Editor/LevelEditorWindow.cs`: добавить выбор сектора
   для выбранного тела (enum-попап в стиле остальных полей окна; сериализация
   через EditorJsonUtility — enum сериализуется автоматически, отдельного кода
   не нужно). В `LevelEditorSceneView.cs` — опционально подписать сектор текстом
   возле имени тела (помогает проверке; если делается — коротко).
4. Заполнить сектора в ассете `Assets/ScriptableObjects/AlphaMap01.asset`
   правкой YAML: у каждого тела в списке Bodies добавить строку поля Sector
   (целое: Hub=0, Near=1, Mid1=2, Mid2=3, Far=4) — стиль записи должен
   совпадать с соседними полями тела в YAML (см., как выглядит `HasStation`).
   Правила заполнения по геометрии от планеты старта (StartPlanetIndex,
   по докам называется «Рут» — имя проверить в файле): она получает Hub;
   остальные — по дистанции от неё: до ~800 юнитов Near, ~800–1400 Mid1,
   ~1400–2000 Mid2, дальше Far. Дистанции посчитать по фактическим позициям
   тел в ассете (Position × Radius уже учтены в «до ~800» границах — считать
   от центра до центра). Звёзды тоже получить сектор по той же дистанции.
   Не трогать другие поля и .meta ассета. После правки перечитать файл и
   проверить, что структура YAML не сломана.
5. На карте (MapScreenBinder) сектор НЕ отображать — только данные.
