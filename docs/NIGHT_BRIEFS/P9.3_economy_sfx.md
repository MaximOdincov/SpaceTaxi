## ЗАДАЧА

1. **Новые SoundId при отсутствии подходящих существующих** (проверь каталог:
   UiClick/ComputerPing уже есть — если ComputerPing нигде не использован,
   ИСПОЛЬЗУЙ его как «новый заказ», не создавай дубль):
   `OrderPing` (если пинг не занят), `BoardBip` (пассажир сел), `DeliveryChime`
   (аккорд), `TaskSuccess`, `TaskFail`, `PurchaseCash`, `DebtTone`,
   `DismissalTone`.
2. **Хуки** (смотри ФАКТИЧЕСКИЕ события; вызов Sound.Play(id) — из владельца
   события, не из UI):
   - Новый заказ: OrderService — добавь событие `event Action OfferAdded`
     (файр при AddOffer; OffersChanged не годится — он и на протухание).
     Подписчик (ToastNotifier-стиль или GameSession) → OrderPing.
   - Пассажир сел: существующий PassengerBoarded → BoardBip.
   - Доставка: OrderDelivered → DeliveryChime.
   - Задание: успех/осечка — смотри фактический код П5.3/П8.1 (там есть
     состояния/события задач); если события нет — добавь
     `event Action<PassengerTask> TaskResolved` в OrderService (при
     фиксации Succeeded/Failed) и подпишись → TaskSuccess/TaskFail.
   - Покупка корабля: магазин П3.2 (UI знает действие) → PurchaseCash;
     досрочное гашение долга (П3.3) → DebtTone при успехе; долг +400
     (RegisterAccident → DebtChanged рост) → DebtTone (подписка, как тост
     П2.2 — только на рост).
   - Увольнение: DismissalScreenController.Show → DismissalTone.
3. **Музыкальный плеер в борткомпе** (новая секция, стиль существующих секций
   фабрики, биндинг в OnboardBinder):
   - Данные: треки = Music-записи AudioCatalog (собери список SoundId с
     Group == Music из catalog; смотри фактический AudioCatalog API —
     если перечисления нет, добавь метод-обход entries). Пусто → секция
     показывает «Треки не найдены» (не падает).
   - AudioManager: добавить playlist-API: `void PlayPlaylistNext(int dir)`
     / `void ToggleMusicPause()` / свойства `SoundId CurrentTrack { get; }`,
     `bool MusicPaused { get; }` + событие `event Action MusicStateChanged`
     (имя/состояние для UI). Реализация поверх существующих musicA/musicB
     (кроссфейд сохранён; пауза — mute/暂停 источника, НЕ Time.timeScale).
     Первый запуск плеером — продолжает то, что играет (MusicFlight в игре).
   - UI секция: строка «МУЗЫКА · <Имя трека>» (имя — DisplayName трека или
     SoundId), кнопки ⏮ ▶/⏸ ⏭ (текстовые глифы, как соседние кнопки),
     прогресс-бар (полоса + доля clip position/length, обновление в
     SlowUpdate 0.25 с). Кнопки — через общий UiClick (П9.1).
4. **Слоты для владельца**: допиши таблицу в GameInfo/05_AUDIO.md (раздел
   «Слоты беты» от П9.2 — дополнение): ожидаемые файлы sfx_order_ping.ogg,
   sfx_board_bip.ogg, sfx_delivery_chime.ogg, sfx_task_success.ogg,
